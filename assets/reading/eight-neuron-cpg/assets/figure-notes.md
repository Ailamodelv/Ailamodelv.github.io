# 图件与数据说明

这些图为本文自行绘制的教学图或数值重算图，没有复制论文原图。静态图同时提供 PNG 和 SVG；SVG 中的文字已转为路径，不依赖阅读设备安装中文字体。交互页面位于 `../interactive/`，包含所需脚本和数据，可直接双击打开，无需网络或本地服务器。

## 提前量与峰值延迟的约定

正文沿用 `xi(t)=x1(t+φiT)`，正 `φi` 表示提前。图 02 与对应交互页的横轴是事件时间，峰值延迟为 `di=(−φi) mod 1`。Walk 的提前量 `[LH,RH,RF,LF]=[0,1/2,1/4,3/4]`，因此峰值依次位于 `[0,1/2,3/4,1/4]` 个周期。交互曲线使用 `0.5+0.5cos[2π(t/T−di)]`。其余四种步态的 0 或半周期取值在变换下不变。

## 完整网络重算的设置

- 来源：Liu et al. (2025) 论文方程与参数表；作者公开代码固定版本 `cef012f12fed7316e307034d48f9c13df909de15`。
- 八节点状态一起采用 RK4 积分，积分步长 `0.0001 s`，总计算时间 `12 s`。
- 节点 1 图示时间为 `10.5929–11.3689 s`，通常每 `0.0005 s` 取一个绘图点，另保留部分事件点。
- 这是启动约 10 s 后的周期运动片段，仍有微小逐周期变化；没有宣称获得完全相同的严格限环或完成物理机器人复现。
- `r = sigmoid(fc - 2000y + 2000z)` 是中间计算量。`X=x,Y=10y,Z=30z` 只是用于同轴比较的变量缩放。
- 交互图中的“固定 `r=0.8`”是另外定义的教学对照，不是论文正常八节点网络的控制设定。

## 目标角数据的含义

- 数据文件：`data/joint-targets.json`，388 行，绝对时间 `10.594–11.368 s`，相邻控制样本间隔 `0.002 s`。
- 原始列 `xd1,xd5` 为各节点最近一个 RK4 积分步的 `x` 有限差分，尚未除以 50。送入 MLP 的最后一个输入特征为该值 `/50`。
- 髋身份 `[0,1,0]`、膝身份 `[1,1,0]`；Walk 编码 `[1,0,0,0,0]`；步幅指令取 `1.0`。
- 使用作者公开的 `best_model_v1.2.pt` 计算，网络为 `11→24→12→1`。本包不包含该权重或作者原始源代码。
- 原作者公开推理脚本中有步幅 `0.8` 的硬编码；本教学重算有意使用 `1.0`，因此不是未经改动运行那个脚本所得的录像复现。
- `qhip_rad,qknee_rad` 为网络输出的弧度值；`qhip_deg,qknee_deg` 仅用于阅读展示。
- 所有这些角度都是目标角，不是实测角，也不是已公开的训练标签。图中没有表示足端轨迹真实跟踪误差。

### 相同髋角的两个交点

在相邻的 2 ms 样本之间作线性插值：

| 交点 | 绝对时间 / s | 髋目标角 / ° | 膝目标角 / ° | 髋角趋势 |
|---|---:|---:|---:|---|
| A | 10.658629 | 60 | -123.7378 | 增大 |
| B | 10.813907 | 60 | -134.9097 | 减小 |

膝角相差约 `11.1719°`。这不是在两个插值时刻重新运行 MLP 的精确推理结果；它是已计算角度序列的线性插值。

## 孤立节点教学数据

`data/single-node.json` 保留此前教学图使用的单节点数据。初态为 `(1,0.04,0.016)`，图示时间 `8.000–8.496 s`，输出采样间隔 `0.001 s`。保留的数据没有记录原始积分器，因而没有把这组孤立节点数据标为 RK4；RK4 说明仅适用于上述完整八节点重算。

## 重绘与许可

`build-figures.py` 从三个随包 JSON 数据文件重绘六张静态图。需要 Python 3、NumPy、Matplotlib 和中文字体。省略 `--font` 时自动选择包含所需字符的系统中文字体；未找到时给出提示并停止，不会生成乱码图。数据读取与输出都相对脚本自身目录定位，可从任意工作目录运行：

```bash
python assets/build-figures.py --font /path/to/chinese-font.ttf
```

交互页面由已有教学可视化导出，并去除宿主环境桥接代码。各页独立内联所需 D3 7.9.0；第三方库采用 ISC 许可证，见 `../vendor/d3-LICENSE.txt`。页面不依赖 ChatGPT、外部 CDN、接口调用、身份或登录会话。
