> **对应分节**：Part 1 — State, action, policy 等；Part 2 — Reward, return, MDP 等。  
> **教材对应**：*Mathematical Foundations of Reinforcement Learning*，Chapter 1: Basic Concepts。

本篇依据作者公开课程大纲、配套课件和教材第一章核对知识范围，并重新组织解释。文中的六状态网格、算例和机器人例子为自编辅助材料，不是课程原例的逐字转录。标为「理解补充」的内容用于澄清容易混淆的地方。

## 0. 本课要解决什么问题

强化学习要研究的是：**一个能够作出决策的主体，如何根据与环境交互得到的反馈，逐渐找到长期表现更好的行为规则。**

第一课先建立描述这件事的语言。它暂时不要求掌握某个训练算法，而是要回答以下问题：

| 问题 | 对应概念 |
| --- | --- |
| 当前处于什么情况？ | 状态 State |
| 当前可以作出什么选择？ | 动作 Action |
| 作出选择后，环境会怎样变化？ | 状态转移 State transition |
| 在不同情况下，应该怎样选择动作？ | 策略 Policy |
| 这一步得到了什么反馈？ | 奖励 Reward |
| 一连串行为的整体结果怎样？ | 轨迹 Trajectory、回报 Return |
| 一次交互什么时候结束？ | 回合 Episode、终止状态 Terminal state |
| 怎样把这些概念放进统一数学框架？ | 马尔可夫决策过程 MDP |

这些内容分别对应第一课的两个视频分节。状态价值、动作价值和贝尔曼公式的正式定义与推导放在第 2 课；本篇只在结尾说明它们为什么会被引入。[课程大纲][course]、[教材第一章][chapter1]

## 1. 从一个具体任务认识交互过程

### 1.1 一个贯穿全文的六状态网格

设想一个移动机器人在下面的网格中行动：

| 位置 | 第 1 列 | 第 2 列 | 第 3 列 |
| --- | --- | --- | --- |
| 第 1 行 | A：起点 | B：普通格 | C：普通格 |
| 第 2 行 | D：普通格 | E：惩罚格 | F：目标格 |

机器人每一步可以选择上、右、下、左或停留。先采用以下确定性规则：

1. 上、右、下、左表示尝试移动一个格子。
2. 尝试越界时留在原地，并获得奖励 $`-1`$。
3. **E 格允许进入**，但动作执行后落在 E 格会获得奖励 $`-2`$。
4. 未越界且动作执行后落在 F 格，获得奖励 $`+5`$；在 F 格选择停留也获得 $`+5`$。
5. 其他情况获得奖励 $`0`$。
6. 基础版本中，到达 F 后仍可继续行动，F 不是自动终止的状态。

奖励规则按上述顺序判断。例如，在 F 格向右越界时获得 $`-1`$，而不是因为仍位于 F 就获得 $`+5`$。

这里已经能看出一个问题：从 A 出发，走上方路线和走经过 E 的下方路线都能到达 F，但过程的质量不同。强化学习需要能够表达这种差别，而不只是记录「有没有到达目标」。

### 1.2 智能体与环境

**智能体（agent）**是作出决策的主体；**环境（environment）**根据当前情况和动作产生后续变化，并返回反馈。

在这个例子中，可以把机器人看作智能体，把网格及其移动、计分规则看作环境。用于更精细的控制建模时，也可以把控制器作为智能体，把机器人本体的动力学和地面一起放入环境；这条边界由建模目的决定。

在时刻 $`t`$，一次交互可以分解为：

| 顺序 | 发生的事情 | 记号 |
| --- | --- | --- |
| 1 | 智能体处于当前状态 | $`S_t`$ |
| 2 | 根据策略选择动作 | $`A_t`$ |
| 3 | 环境执行一次转移，产生下一状态和本次奖励 | $`S_{t+1}, R_{t+1}`$ |
| 4 | 在新状态下继续选择动作 | $`A_{t+1}`$ |

因此，一个交互片段写为：

```math
S_t,\ A_t,\ R_{t+1},\ S_{t+1},\ A_{t+1},\ R_{t+2},\ S_{t+2},\ldots
```

这里统一采用「动作 $`A_t`$ 对应奖励 $`R_{t+1}`$」的下标约定。它强调奖励来自这次动作之后的环境反馈。不同资料也可能用 $`R_t`$ 记这笔奖励，阅读时应先核对约定。

**符号约定**：大写 $`S_t,A_t,R_{t+1}`$ 表示随机变量，小写 $`s,a,r`$ 表示具体取值。例如 $`S_t=A`$ 表示当前状态恰好是 A 格。

## 2. 状态与动作：用什么描述问题

### 2.1 状态 State

状态是对系统当前情况的数学描述。在上述网格里，位置就足以决定后续移动和奖励规则，因此可以取：

```math
\mathcal S=\lbrace A,B,C,D,E,F\rbrace.
```

$`\mathcal S`$ 称为**状态空间**，即所有可能状态的集合。

这个例子中「位置足够」依赖具体假设：移动规则不受速度、朝向、电量或历史影响。若加入「电量不足时不能移动」，状态就需要包含电量；若机器人只能向身体前方移动，通常还需要加入朝向。

这也说明，状态不是随便选几个容易测量的量。它需要保留与预测后续变化有关的信息。第 9 节会用马尔可夫性质把这个要求写得更准确。

### 2.2 动作 Action

动作是智能体能够作出的选择。在六状态网格中：

```math
\mathcal A(s)=\lbrace\uparrow,\rightarrow,\downarrow,\leftarrow,\mathrm{stay}\rbrace.
```

$`\mathcal A(s)`$ 表示状态 $`s`$ 下的动作空间。写成带 $`s`$ 的形式，是因为**不同状态可以有不同的可用动作**。

以边界为例，至少有两种合理建模方式：

| 建模方式 | 位于顶边时能否选择「向上」？ | 结果 |
| --- | --- | --- |
| 保留动作并定义后果 | 能 | 留在原地，可能受到越界惩罚 |
| 从动作空间移除该动作 | 不能 | 策略只能在剩余动作中选择 |

两种方式都可以使用，但对应的决策问题不同。本篇例子采用第一种。

### 2.3 动作不等于动作结果

「选择向右」是动作，「最后到了哪个格子」是转移结果。环境存在随机性时，二者不能混为一谈。

机器人控制中也有类似区别：动作可以是目标关节角、关节力矩或其他控制指令；实际关节运动由指令、动力学和接触共同决定。

**理解补充**：本课主要使用有限状态、有限动作的例子，方便用表格表示。连续关节角和连续力矩属于连续空间，基本概念相同，但概率表达与计算方法会有所变化。

## 3. 状态转移：环境如何回应动作

### 3.1 确定性转移

从 A 选择向右，必然到 B：

```math
A\xrightarrow{\rightarrow}B.
```

从 A 选择向上，则因越界留在 A：

```math
A\xrightarrow{\uparrow}A.
```

确定性转移可以写成函数：

```math
s_{t+1}=f(s_t,a_t).
```

对有限网格，也可以使用「当前状态 × 动作」的表格：每个单元格记录唯一的下一状态。

### 3.2 状态转移概率

更一般地，用条件概率描述环境：

```math
p(s'\mid s,a)
=\Pr(S_{t+1}=s'\mid S_t=s,A_t=a).
```

读法是：**当前在 $`s`$，已经选择了动作 $`a`$，下一步到达 $`s'`$ 的概率。**

对于任意固定的 $`(s,a)`$，都有：

```math
p(s'\mid s,a)\geq 0,
\qquad
\sum_{s'\in\mathcal S}p(s'\mid s,a)=1.
```

确定性情况包含在这个写法中。例如：

```math
p(B\mid A,\rightarrow)=1,
\qquad
p(s'\mid A,\rightarrow)=0\quad(s'\neq B).
```

假设另一个有打滑的版本中，向右有 $`80\%`$ 的概率成功、$`20\%`$ 的概率原地不动，则：

```math
p(B\mid A,\rightarrow)=0.8,
\qquad
p(A\mid A,\rightarrow)=0.2.
```

**确定性转移是概率集中在一个结果上的特殊情况。**用概率并不意味着环境一定随机。

### 3.3 「不希望进入」与「不能进入」是两种规则

惩罚格不等于物理障碍。六状态例子中，机器人可以进入 E，只是要付出负奖励。如果 E 被墙完全封住，状态转移规则就应阻止机器人进入。

因此需要分别问：

- **能不能发生？**由动作约束、状态转移等规则决定。
- **发生后有多好或多差？**由奖励规则表达。

设置较大的负奖励，不等于从数学上排除了该行为。

## 4. 策略：在每个状态下如何选择动作

### 4.1 策略的定义

策略用 $`\pi`$ 表示。对本课讨论的平稳马尔可夫策略：

```math
\pi(a\mid s)
=\Pr(A_t=a\mid S_t=s).
```

它回答：**当状态是 $`s`$ 时，智能体以多大概率选择动作 $`a`$？**

这里「平稳」表示这张规则表不随时间改变；「马尔可夫策略」表示它根据当前状态作决策。策略也可以用更一般的形式描述，但本课先从这种形式开始。

对每个状态 $`s`$：

```math
\pi(a\mid s)\geq 0,
\qquad
\sum_{a\in\mathcal A(s)}\pi(a\mid s)=1.
```

### 4.2 确定性策略

确定性策略在每个状态指定一个动作。例如：

| 状态 | 指定动作 | 在确定性网格中的结果 |
| --- | --- | --- |
| A | 向右 | 到 B |
| B | 向右 | 到 C |
| C | 向下 | 到 F |
| D | 向上 | 到 A |
| E | 向右 | 到 F |
| F | 停留 | 留在 F |

在 A 状态，这意味着：

```math
\pi(\rightarrow\mid A)=1,
\qquad
\pi(a\mid A)=0\quad(a\neq\rightarrow).
```

也可以将确定性策略写成动作函数 $`a=\mu(s)`$。两种写法表达同一规则。

### 4.3 随机策略

如果在 A 以 $`60\%`$ 的概率向右、$`40\%`$ 的概率向下：

```math
\pi(\rightarrow\mid A)=0.6,
\qquad
\pi(\downarrow\mid A)=0.4.
```

其他动作的概率为零。

这表示每次到达 A 时按该分布选择**一个动作**，不是同时执行 $`0.6`$ 份向右和 $`0.4`$ 份向下。

### 4.4 策略与转移概率必须分清

| 表达式 | 条件是什么？ | 谁的行为被描述？ |
| --- | --- | --- |
| $`\pi(a\mid s)`$ | 已知当前状态 | 智能体如何选择动作 |
| $`p(s'\mid s,a)`$ | 已知当前状态和已选动作 | 环境如何产生下一状态 |

于是有四种组合：

| 策略 | 环境转移 | 从同一状态出发的可能表现 |
| --- | --- | --- |
| 确定性 | 确定性 | 动作和状态序列确定 |
| 随机 | 确定性 | 动作选择使状态序列可能不同 |
| 确定性 | 随机 | 相同动作仍可能产生不同下一状态 |
| 随机 | 随机 | 两种随机性共同影响状态序列 |

这张表只讨论动作和状态。即使它们都确定，奖励本身也仍可能随机。

### 4.5 策略不是一条预先写好的路线

路线记录一次实际经过的状态，而策略规定在不同状态下怎样行动。

例如，预先安排的路线可能是 A、B、C、F；如果发生偏移，机器人到了 D，就需要知道 D 对应的动作。完整策略能够描述这种情况，单条路线本身不能。

同样，**固定策略不等于固定运动序列**。只要状态发生变化，同一个策略就可能给出不同动作。

## 5. 奖励：把希望实现的行为写成反馈

### 5.1 单步奖励是什么

奖励 $`R_{t+1}`$ 是执行动作 $`A_t`$ 后得到的一个实数反馈。

六状态网格中的几个例子是：

| 当前状态 | 动作 | 下一状态 | 本次奖励 |
| --- | --- | --- | --- |
| A | 向右 | B | $`0`$ |
| A | 向上 | A | $`-1`$ |
| A | 停留 | A | $`0`$ |
| D | 向右 | E | $`-2`$ |
| C | 向下 | F | $`+5`$ |
| F | 停留 | F | $`+5`$ |

奖励表达了设计者希望智能体重视什么。在本例中，越界和处于 E 受到惩罚，处于 F 得到较高奖励。

但奖励不是一句自然语言指令。若设计者心里想的是「安全、快速地到达目标」，却没有在奖励、约束和终止规则中表达清楚，那么最大化回报未必等于完成这个真实意图。

### 5.2 正奖励、负奖励与相对大小

在最大化回报的约定下，其他条件相同时，较大的奖励更有利。正数常用于鼓励，负数常用于惩罚，但正负号本身不决定动作的全部价值。

例如，两个动作分别带来 $`-1`$ 和 $`-10`$，若后续完全相同，前者更好。也可能一个动作眼前损失 $`-1`$，却为后续较大的收益创造条件。

因此要同时考虑：

- 这一步奖励与其他选择相比怎样；
- 这个动作会把系统带入什么状态；
- 后续还能获得怎样的奖励。

本课先建立这种长期比较的意识，具体计算工具会在后续课程中出现。

### 5.3 奖励也可以随机

课程用奖励概率描述一般情况：

```math
p(r\mid s,a)
=\Pr(R_{t+1}=r\mid S_t=s,A_t=a).
```

对于离散奖励：

```math
p(r\mid s,a)\geq 0,
\qquad
\sum_{r\in\mathcal R(s,a)}p(r\mid s,a)=1,
```

其中 $`\mathcal R(s,a)`$ 是给定状态和动作后，可能出现的奖励值集合。

确定性奖励对应一个取值的概率为 $`1`$。例如：

```math
p(-1\mid A,\uparrow)=1.
```

**理解补充：奖励样本与期望奖励。**如果一个动作有 $`0.7`$ 的概率获得 $`2`$，有 $`0.3`$ 的概率获得 $`-1`$，它的一步期望奖励是：

```math
\bar r(s,a)
=\mathbb E[R_{t+1}\mid S_t=s,A_t=a]
=\sum_r r\,p(r\mid s,a)
=0.7\times2+0.3\times(-1)=1.1.
```

实际某次得到的奖励仍是 $`2`$ 或 $`-1`$，不是必然得到 $`1.1`$。$`\bar r`$ 在这里专门表示期望，避免与奖励随机变量混淆。

### 5.4 奖励是否依赖下一状态

**可以依赖。**例如「落在目标格就得到较高奖励」显然与实际到达的格子有关。

课程使用 $`p(r\mid s,a)`$，是把可能的下一状态综合起来，得到当前状态、动作之下的奖励分布。离散情况下，全概率公式给出：

```math
p(r\mid s,a)
=\sum_{s'\in\mathcal S}
p(r\mid s,a,s')\,p(s'\mid s,a).
```

假设从某个格子执行动作后，有 $`0.8`$ 的概率到达 F 并得到 $`5`$，有 $`0.2`$ 的概率停在普通格并得到 $`0`$。那么，即使暂时还不知道实际下一状态，也能写出：

```math
p(5\mid s,a)=0.8,
\qquad
p(0\mid s,a)=0.2.
```

这并没有消除奖励与下一状态之间的联系，只是对下一状态做了概率汇总。教材第一章 §1.9 专门解释了这个问题。[教材第一章][chapter1]

反过来，**下一状态也未必足以单独决定奖励**：在 A 向上越界和在 A 停留，下一状态都是 A，奖励却分别为 $`-1`$ 和 $`0`$。

**理解补充：更一般的联合写法。**若需要同时描述下一状态与奖励，可以写：

```math
p(s',r\mid s,a)
=p(s'\mid s,a)\,p(r\mid s,a,s').
```

通常不能直接把右边最后一项替换为 $`p(r\mid s,a)`$；那需要额外的条件独立假设。第一次学习时，理解「奖励与转移结果可以有关」即可。

## 6. 轨迹：一次实际交互留下什么记录

轨迹是状态、动作和奖励串成的序列：

```math
\tau=(s_0,a_0,r_1,s_1,a_1,r_2,s_2,\ldots).
```

在六状态网格中，上方路线产生以下片段：

| 时刻 $`t`$ | 当前状态 $`s_t`$ | 动作 $`a_t`$ | 奖励 $`r_{t+1}`$ | 下一状态 $`s_{t+1}`$ |
| --- | --- | --- | --- | --- |
| 0 | A | 向右 | 0 | B |
| 1 | B | 向右 | 0 | C |
| 2 | C | 向下 | 5 | F |

如果到达 F 后继续停留，后面还会不断追加「F、停留、5、F」的记录。

轨迹是策略与环境共同作用后的一次具体结果。随机情形下，同一策略、同一起点也可能产生不同轨迹。

还要区分：**有限长度的轨迹片段不一定是完整回合。**上表可以只是持续任务的前三步记录；是否构成一个回合，要看任务有没有在 F 终止。

## 7. 回报与折扣：怎样评价一连串行为

### 7.1 奖励与回报的区别

奖励关注某一步的反馈；回报把从当前时刻开始的后续奖励合在一起。

若轨迹在时刻 $`T`$ 结束，未折扣回报为：

```math
G_t=R_{t+1}+R_{t+2}+\cdots+R_T.
```

为了先做有限计算，**这一小节临时采用「首次到达 F 就结束」的回合版本**。这是对基础例子的明确修改。

从 A 经 B、C 到 F，奖励依次为 $`(0,0,5)`$，回报为 $`5`$；从 A 经 D、E 到 F，奖励依次为 $`(0,-2,5)`$，回报为 $`3`$。

两个过程都到达目标，但回报区分了是否经过惩罚格。

与此同时，从 A 出发的第一步，无论向右还是向下，奖励都是 $`0`$。只看即时奖励，无法分辨后面的差别。

### 7.2 为什么引入折扣回报

回到第 1 节的持续任务版本：到达 F 后，每次停留仍获得 $`5`$。直接相加会出现：

```math
0+0+5+5+5+\cdots=+\infty.
```

为了在这类无限时域任务中得到有限的评价量，引入折扣因子 $`\gamma`$。对于有界奖励，通常取 $`0<\gamma<1`$，定义：

```math
\boxed{
G_t=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1}
=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots
}
```

同一个符号 $`G_t`$ 可以表示不同约定下的回报；下面除非特别说明，均采用折扣形式。

注意下标与幂次：

- 执行当前动作后得到的 $`R_{t+1}`$，系数是 $`1`$。
- 再下一步的 $`R_{t+2}`$，系数是 $`\gamma`$。
- 第三个奖励 $`R_{t+3}`$，系数是 $`\gamma^2`$。

有限回合也可以折扣，只需把上限改为 $`T-t-1`$：

```math
G_t=\sum_{k=0}^{T-t-1}\gamma^kR_{t+k+1}.
```

### 7.3 折扣因子影响什么

**$`\gamma`$ 越接近 $`1`$，远期奖励的权重衰减越慢；越接近 $`0`$，评价越偏重近期奖励。**

例如，第 6 个奖励的权重是 $`\gamma^5`$：

| $`\gamma`$ | 当前奖励权重 | 第 6 个奖励权重 $`\gamma^5`$ |
| --- | --- | --- |
| 0.5 | 1 | 0.03125 |
| 0.9 | 1 | 0.59049 |
| 0.99 | 1 | 约 0.95099 |

远期的单个奖励并不会因为 $`\gamma`$ 接近 $`1`$ 就自动比即时奖励更重要；它只是被削弱得更少。远期累计贡献有多大，还要看奖励的数值和持续时间。

$`\gamma=0`$ 是只看即时奖励的退化情况。有限回合可以使用 $`\gamma=1`$ 的未折扣回报；无限持续任务使用 $`\gamma=1`$ 时，直接求和一般不能保证收敛。

**$`\gamma`$ 是长期目标的一个参数，不是学习率。**增大它也不直接意味着策略更鲁棒或训练效果一定更好。

### 7.4 有界奖励为什么能保证折扣和有限

假设每一步奖励满足 $`\lvert R_{t+1}\rvert\leq R_{\max}`$。那么：

```math
\lvert G_t\rvert
\leq\sum_{k=0}^{\infty}\gamma^k\lvert R_{t+k+1}\rvert
\leq R_{\max}\sum_{k=0}^{\infty}\gamma^k
=\frac{R_{\max}}{1-\gamma}.
```

这使用了等比级数：

```math
1+\gamma+\gamma^2+\cdots=\frac{1}{1-\gamma},
\qquad 0<\gamma<1.
```

所以更准确的说法是：**有界奖励与小于 $`1`$ 的非负折扣因子共同保证无限折扣回报有限。**

### 7.5 完整算例：终止方式会改变回报

取 $`\gamma=0.8`$，比较两条路线。

**情况一：首次到达 F 后终止。**

```math
G_0^{\mathrm{upper}}
=0+0.8\times0+0.8^2\times5
=3.2.
```

```math
G_0^{\mathrm{lower}}
=0+0.8\times(-2)+0.8^2\times5
=1.6.
```

**情况二：到达 F 后永久停留，每步继续获得 $`5`$。**

上方路线的奖励序列是 $`(0,0,5,5,5,\ldots)`$：

```math
G_0^{\mathrm{upper}}
=5\sum_{k=2}^{\infty}0.8^k
=\frac{5\times0.8^2}{1-0.8}
=16.
```

下方路线的奖励序列是 $`(0,-2,5,5,5,\ldots)`$：

```math
G_0^{\mathrm{lower}}
=0.8\times(-2)+\frac{5\times0.8^2}{1-0.8}
=14.4.
```

| 目标处的处理 | 上方路线回报 | 下方路线回报 |
| --- | --- | --- |
| 到达即终止 | 3.2 | 1.6 |
| 此后每步得到 5 | 16 | 14.4 |

本例中路线的优劣次序没有变化，但回报数值明显不同。其他任务中，改变目标处的后续规则也可能改变最佳策略。

### 7.6 回报的递推关系：为下一课作准备

把折扣和的第一项单独拿出：

```math
\begin{aligned}
G_t
&=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots\\
&=R_{t+1}+\gamma\left(R_{t+2}+\gamma R_{t+3}+\cdots\right)\\
&=R_{t+1}+\gamma G_{t+1}.
\end{aligned}
```

这是**同一条轨迹上回报的递推关系**。它还不是下一课将正式推导的贝尔曼公式，但会成为理解那个公式的重要起点。

对于在 $`T`$ 时刻终止的有限回合，约定 $`G_T=0`$，同样可以使用这个递推关系。

### 7.7 一次回报高，不足以证明策略总体更好

随机策略或随机环境会让回报也成为随机变量。同一策略有时运气好、有时运气差；起点不同，也可能产生不同结果。

因此，评价策略通常需要在明确起始状态或起始状态分布之后，考察回报的期望，而不是只比较某一次轨迹。本课先记住这个问题，第 2 课将用状态价值等概念正式处理它。

### 7.8 理解补充：所有奖励都加一个常数，会怎样

教材第一章问答提出了奖励整体平移的问题。理解其结论时，应保留任务条件。[教材第一章 §1.9][chapter1]

对于统一的无限时域折扣目标，如果每一步都改为 $`R_{t+1}'=R_{t+1}+b`$，且 $`0<\gamma<1`$，则：

```math
G_t'
=\sum_{k=0}^{\infty}\gamma^k(R_{t+k+1}+b)
=G_t+\frac{b}{1-\gamma}.
```

所有策略的回报都增加同一个常数，因此按期望回报比较时，策略优劣次序不变。若再乘以同一个正数，也不改变这种次序。

但如果是长度会随策略改变的回合，而且**只在终止前**给每步奖励加 $`b`$，新增的总量为：

```math
b\sum_{k=0}^{T-t-1}\gamma^k.
```

它会随回合长度 $`T-t`$ 改变，因而可能改变「早点结束」与「多待几步」的偏好。不能脱离任务条件，笼统地说所有奖励加常数永远没有影响。

## 8. 回合、终止与吸收：交互何时结束

### 8.1 回合式任务与持续式任务

**回合（episode）**是从一次起始到终止所形成的完整交互过程，通常包含有限步。

| 任务形式 | 关键特点 | 示例 |
| --- | --- | --- |
| 回合式任务 Episodic task | 有定义清楚的终止条件 | 走出迷宫后本轮结束 |
| 持续式任务 Continuing task | 没有任务本身规定的自然终点 | 持续调节设备，使其保持运行 |

机器人训练可以规定摔倒后结束本回合，再从初始状态重新开始。这里的「重新开始」是开始新回合，不属于上一回合结束前的奖励序列。

**理解补充**：实验或训练程序截取一段固定长度数据，不一定意味着真实任务在那个时刻终止。任务终止与为了收集数据而截断轨迹，应当在建模时分开。

### 8.2 目标状态、终止状态、吸收状态

这三个名称分别强调不同事情：

| 概念 | 定义重点 | 能否在后续离开？ |
| --- | --- | --- |
| 目标状态 Target state | 任务希望到达或维持的状态 | 由环境规则决定 |
| 终止状态 Terminal state | 到达后，当前回合结束 | 本回合不再继续交互 |
| 吸收状态 Absorbing state | 一旦进入，环境后续转移无法离开 | 在其允许的动作下均不能离开 |

三者可以通过设计相互关联，但不能自动画等号。

例如，在六状态基础网格中，F 是目标格。策略可以选择停留，也可以选择向上回到 C。**某个策略决定一直留在 F，不代表环境把 F 规定成了吸收状态。**

在已固定策略所诱导的状态链中，F 可能表现为吸收态；这与「无论采取哪个允许动作，都无法离开」的环境吸收态是不同层面的说法。

### 8.3 用零奖励吸收状态统一表示回合

若原任务在 $`s_{\mathrm{term}}`$ 结束，可以为了数学表达方便，在终止后补上一个永远不离开、奖励始终为零的后续过程：

```math
p(s_{\mathrm{term}}\mid s_{\mathrm{term}},a)=1,
\qquad
R_{t+1}=0\quad\text{在终止后的各步}.
```

于是，原来的有限奖励序列后面只追加零，不改变回报。进入终止状态那一步原本应获得的奖励仍然保留。

若追加的却是每步正奖励，就改变了任务的回报定义。第 7 节的 $`3.2`$ 与 $`16`$，正是这种差异的一个例子。

### 8.4 对应课程时需要留意的设定

课程的网格例子把目标格按普通状态处理：智能体可以离开，也可以停留；在目标处持续停留可以继续获得正奖励。因此，学习视频里的无限折扣回报时，要按这个设定理解。[第一课课件][slides-current]、[教材 §1.6][chapter1]

本篇第 7 节同时计算了「到达即终止」与「持续奖励」两个版本，是为了把这个建模差异展示出来。

## 9. 马尔可夫决策过程：把概念放入统一框架

### 9.1 马尔可夫性质到底是什么意思

马尔可夫性质强调：**给定当前状态和动作后，过去的历史不再提供预测下一步所需的额外信息。**

设截至当前的历史为：

```math
h_t=(s_0,a_0,r_1,s_1,\ldots,a_{t-1},r_t,s_t).
```

对下一状态，可以写：

```math
p(s_{t+1}\mid h_t,a_t)
=p(s_{t+1}\mid s_t,a_t).
```

对下一步奖励，类似地有：

```math
p(r_{t+1}\mid h_t,a_t)
=p(r_{t+1}\mid s_t,a_t).
```

更完整的环境马尔可夫假设应对下一状态与奖励的联合分布成立。使用第 5 节的记号，它写为：

```math
p(s_{t+1},r_{t+1}\mid h_t,a_t)
=p(s_{t+1},r_{t+1}\mid s_t,a_t).
```

这个联合条件也蕴含上面的两个边缘分布等式。

这不表示过去没有影响。过去的作用已经通过当前状态体现出来；关键在于当前状态是否保留了足够的信息。

### 9.2 为什么只看位置或关节角，可能不够

考虑一个有惯性的运动物体。两次观测中位置完全相同，但一次向右高速运动、一次静止。施加同样的力后，它们的下一位置通常不同。

如果状态只记录位置，过去的运动情况仍提供额外预测信息；若把速度一并纳入，就更接近一个充分的动力学状态。

机器人也是如此：相同的关节角度，并不意味着相同的关节速度、机身运动或接触情况。是否满足马尔可夫性质，要结合具体动力学和状态选择判断。

### 9.3 理解补充：状态与观测

**状态（state）**指模型中足以描述系统的变量；**观测（observation）**指智能体实际能获得的信息。

在简单网格中，两者可以相同：智能体直接知道当前格子。在实际机器人中，传感器可能只能测到部分变量，还包含噪声或延迟，因此一次观测不一定是完整状态。

例如，地面摩擦变化会影响运动，但机器人未必能直接读出摩擦系数。此时，仅把当前传感器读数输入策略，不能自动保证严格的马尔可夫性。

使用历史观测、状态估计等方法，是处理信息不足的可能方式；这些属于后续拓展。本课需要记住：**网络输入向量与数学上的完整状态，不能未经判断就视为同一个概念。**

### 9.4 MDP 包含哪些要素

马尔可夫决策过程（Markov decision process，MDP）把前面讨论的决策问题统一起来。

| 要素 | 本篇记号 | 六状态例子中的含义 |
| --- | --- | --- |
| 状态空间 | $`\mathcal S`$ | A 到 F 六个格子 |
| 可用动作 | $`\mathcal A(s)`$ | 上、右、下、左、停留 |
| 状态转移规律 | $`p(s'\mid s,a)`$ | 执行动作后到达各格子的概率 |
| 奖励规律 | $`p(r\mid s,a)`$ | 当前状态、动作下可能得到的奖励 |
| 马尔可夫假设 | 给定当前状态、动作后无需额外历史 | 当前格子已包含该网格规则所需的信息 |
| 回报的评价约定 | 如折扣因子 $`\gamma`$ | 怎样累计近期与远期奖励 |

对以期望累计回报为目标的问题，有些资料采用以下五元组简写：

```math
\mathcal M=(\mathcal S,\mathcal A,P,\bar r,\gamma).
```

在这一写法中，$`P`$ 表示转移概率，$`\bar r`$ 表示一步期望奖励函数，不能把这里的 $`\bar r`$ 与奖励值集合混淆。若要完整表达随机奖励与下一状态的关系，可以保留 $`p(s',r\mid s,a)`$。元组的具体记法因资料而异，先理解每个量的含义更有用。

**环境规则和策略承担不同角色**：前者描述面对的问题，后者描述准备怎样行动。课程把策略作为 MDP 框架下的重要概念一起介绍；在同一个环境中，仍可以比较、改进许多不同策略。

### 9.5 模型是什么，平稳性又是什么

本课中的环境模型，主要指状态转移和奖励的规律。它不是专指一个神经网络。

例如，已知完整网格的转移表与奖励表，就相当于知道这个简单环境的模型。若只能执行动作并观察结果，却不知道完整概率表，模型就是未知或不完全已知的。

还要区分两个性质：

| 性质 | 回答的问题 |
| --- | --- |
| 马尔可夫性 | 给定当前状态、动作后，更早历史还有没有额外预测作用？ |
| 平稳性 | 同一个状态、动作所对应的环境规律，是否随时间改变？ |

课程主要讨论平稳模型，因此常写 $`p(s'\mid s,a)`$，而不是带时间下标的 $`p_t(s'\mid s,a)`$。[教材 §1.7][chapter1]

一个系统可以具有马尔可夫性，同时其转移规律随时间变化。这两个性质不能相互替代。

### 9.6 固定策略后，得到怎样的过程

固定本课使用的平稳马尔可夫策略 $`\pi`$ 后，每个状态下的动作选择分布就确定了。对所有可能动作求和，得到状态之间的转移概率：

```math
\boxed{
p_\pi(s'\mid s)
=\sum_{a\in\mathcal A(s)}\pi(a\mid s)\,p(s'\mid s,a)
}
```

公式中，每一项表示「先选择动作 $`a`$，再通过该动作转移到 $`s'`$」的概率；求和表示把所有可能动作的贡献合起来。

在平稳环境下，这样得到的状态序列是一个齐次马尔可夫链。若同时保留奖励，就得到通常所说的**马尔可夫奖励过程**。

这解释了课件中「固定策略后，MDP 成为马尔可夫过程」的含义。对于依赖完整历史或随时间变化的策略，需要进一步处理；本课的上述公式针对 $`\pi(a\mid s)`$ 这一类策略。

## 10. 用一次概率计算串起策略与环境

使用第 3 节的打滑变体，设当前位于 A：

- 策略以 $`0.6`$ 的概率向右，以 $`0.4`$ 的概率向下。
- 若向右，环境以 $`0.8`$ 的概率把机器人带到 B，以 $`0.2`$ 的概率让它留在 A。
- 若向下，必然到达 D。

可以用下表把两层概率分开：

| 动作 | 策略选择它的概率 | 给定动作后的环境结果 | 该分支的联合概率 |
| --- | --- | --- | --- |
| 向右 | 0.6 | 到 B：0.8 | $`0.6\times0.8=0.48`$ |
| 向右 | 0.6 | 留 A：0.2 | $`0.6\times0.2=0.12`$ |
| 向下 | 0.4 | 到 D：1 | $`0.4\times1=0.40`$ |

所以：

```math
p_\pi(B\mid A)=0.48,
\qquad
p_\pi(A\mid A)=0.12,
\qquad
p_\pi(D\mid A)=0.40.
```

三者相加等于 $`1`$。

这里不能把 $`0.6`$ 当成最终到 B 的概率，因为它只表示「选择向右」的概率；环境还可能让这次移动失败。

继续重复这一过程，就会生成轨迹；沿轨迹记录奖励并按 $`\gamma`$ 加权，就得到回报。这样，本课的状态、动作、策略、转移、轨迹和回报就联系起来了。

## 11. 理解补充：把本课概念对应到人形机器人

以下是用于理解概念的示意映射，不是某个具体训练系统的完整配置。

| 强化学习概念 | 人形机器人运动控制中的一种对应 |
| --- | --- |
| 智能体 | 负责选择控制指令的控制器 |
| 环境 | 机器人本体动力学、地面、接触、外部扰动 |
| 状态 | 描述关节、机身、接触及任务情况的充分变量 |
| 观测 | 编码器、惯性传感器等实际提供给策略的信息 |
| 动作 | 关节力矩、目标关节角等选定的控制指令 |
| 状态转移 | 指令作用一段时间后，运动和接触状态如何变化 |
| 奖励 | 速度跟踪、运动代价、跌倒等方面的数值反馈 |
| 策略 | 根据输入信息选择动作的规则或函数 |
| 轨迹 | 一次运行记录的状态、动作和奖励序列 |
| 回报 | 对后续运动表现进行累积评价的量 |

### 11.1 为什么相同策略可以产生不同运动

策略根据状态规定动作或动作的概率分布。即使策略参数固定，机器人姿态、速度、接触或任务指令发生变化时，策略输入也会变化，输出动作随之可能变化。

因此，「同一个策略」并不等于「反复播放同一段关节轨迹」。但一个策略是否能适应训练中没有覆盖的地形，还取决于输入信息、训练分布和具体学习结果，不能单靠这个定义保证。

### 11.2 奖励函数与运动策略不是同一个对象

奖励规定怎样评价行为，策略规定怎样作出行为。一个固定的奖励表达式，在不同状态和动作下，也会产生不同奖励数值。

例如，设想一个仅用于解释的奖励：

```math
R_{t+1}
=-w_v\lVert v_{t+1}-v_t^{\mathrm{cmd}}\rVert^2
-w_\tau\lVert\boldsymbol{\tau}_t\rVert^2
-w_f\mathbf{1}_{\lbrace\mathrm{fall}\rbrace},
```

其中 $`v_t^{\mathrm{cmd}}`$ 是该步给定的目标速度，$`v_{t+1}`$ 是动作后速度，$`\boldsymbol\tau_t`$ 是关节力矩向量，三个权重均为正，最后一项表示该步摔倒时产生惩罚。这里用粗体 $`\boldsymbol\tau_t`$ 表示力矩，与第 6 节表示轨迹的 $`\tau`$ 区分。

即使权重固定，不同地形、姿态和控制动作仍会带来不同数值。若任务指令变化，相应信息也应提供给决策过程。

这说明：**固定奖励表达式并不直接限定唯一的一种运动；是否需要调整奖励，是任务与学习方法的进一步问题。**

### 11.3 执行策略与训练策略是两件事

执行策略，是根据当前输入产生动作；训练策略，是使用交互数据改进行为规则。

训练时需要的奖励信号，不一定要在部署执行每一步动作时由策略网络直接接收。同样，一个不显式使用完整转移模型的学习方法，依然在具有真实转移规律的环境中运行。

本课先把这些对象区分开；策略具体怎样更新，会在后续算法课程中展开。

## 12. 概念与公式速查

### 12.1 核心符号

| 符号 | 含义 |
| --- | --- |
| $`S_t, s`$ | 状态随机变量与具体状态 |
| $`A_t, a`$ | 动作随机变量与具体动作 |
| $`R_{t+1}, r`$ | 执行 $`A_t`$ 后的奖励随机变量与具体奖励值 |
| $`\mathcal S`$ | 状态空间 |
| $`\mathcal A(s)`$ | 状态 $`s`$ 下的动作空间 |
| $`\mathcal R(s,a)`$ | 给定状态、动作后可能出现的奖励值集合 |
| $`\pi(a\mid s)`$ | 策略：给定状态后的动作选择概率 |
| $`p(s'\mid s,a)`$ | 状态转移概率 |
| $`p(r\mid s,a)`$ | 奖励概率 |
| $`\bar r(s,a)`$ | 一步期望奖励 |
| $`\tau`$ | 一条轨迹 |
| $`G_t`$ | 从时刻 $`t`$ 开始计算的回报 |
| $`\gamma`$ | 折扣因子 |
| $`p_\pi(s'\mid s)`$ | 固定策略后，状态之间的转移概率 |

### 12.2 三个归一化关系

```math
\begin{aligned}
\sum_{a\in\mathcal A(s)}\pi(a\mid s)&=1,\\
\sum_{s'\in\mathcal S}p(s'\mid s,a)&=1,\\
\sum_{r\in\mathcal R(s,a)}p(r\mid s,a)&=1.
\end{aligned}
```

第一个固定状态、对动作求和；后两个固定状态和动作，分别对下一状态、奖励求和。不要把求和对象弄反。

### 12.3 四组需要分清的关系

| 容易混淆的概念 | 区别 |
| --- | --- |
| 动作与状态转移 | 前者是选择，后者是环境执行后的变化 |
| 策略与轨迹 | 前者是行为规则，后者是一次实际记录 |
| 奖励与回报 | 前者是单步反馈，后者是从当前起累计的反馈 |
| 目标与终止 | 前者表达任务偏好，后者规定本回合结束 |

## 13. 下一课：为什么需要贝尔曼公式

第一课已经知道：行为要从长期回报评价，而随机交互会产生不同的回报。

下一步自然要问：

- 给定策略，从某个状态出发，平均而言能获得多少回报？
- 能否利用「当前一步」与「后续过程」之间的关系来计算它？
- 如果第一步动作也被指定，应该怎样评价这个选择？

第 2 课「贝尔曼公式」将引入状态价值、动作价值，并推导它们满足的关系。复习本课时，尤其应掌握 $`\pi(a\mid s)`$、$`p(s'\mid s,a)`$、$`p(r\mid s,a)`$ 和 $`G_t`$ 的含义，以及它们在一次交互中各自处于什么位置。
