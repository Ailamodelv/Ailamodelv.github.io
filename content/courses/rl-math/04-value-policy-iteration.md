# 《强化学习的数学原理》学习笔记 04：值迭代与策略迭代

> **对应课程**：西湖大学赵世钰《强化学习的数学原理》，第 4 课。  
> **课程分节**：Value iteration、Policy iteration、Truncated policy iteration。  
> **教材对应**：*Mathematical Foundations of Reinforcement Learning*，Chapter 4。  
> **整理日期**：2026-10-24。

前两课分别解释了固定策略的价值方程和最优价值方程。这一课要把方程变成操作流程：**手上只有环境模型和一张初始表时，怎样一步步找到值得执行的策略？**

本篇依据官方课程与教材整理。继续使用第 2、3 课的自编工作区，重点记录算法之间的连接、截断评估以及实现细节。有关初值、压缩证明和三状态追问的完整讨论另有独立文章，文末给出入口；这里把它们放回课程主线。

## 0. 先认清三种算法正在更新什么

| 方法 | 从什么开始 | 每轮的主要工作 | 中间那张表是什么 |
| --- | --- | --- | --- |
| 值迭代 VI | 任意有限价值表 | 按旧表比较动作，再更新一次 | 最优价值的近似，未必对应任何策略的准确价值 |
| 策略迭代 PI | 一套初始策略 | 把策略评估准确，再做贪心改善 | 当前策略的准确价值 |
| 截断策略迭代 | 初始表与策略更新规则 | 选策略后只做有限轮评估 | 所选策略价值的近似 |

本课假设有限状态与有限动作、奖励有界、$`0\leq\gamma<1`$，环境模型已知，且使用精确的表格运算。已知模型意味着能够计算一步期望奖励 $`\bar r(s,a)`$ 和转移概率 $`p(s'\mid s,a)`$。这些方法通常归入动态规划；它们为后面的无模型学习提供结构。

“环境中走一步”和“计算时更新一轮”要分开。以下 $`k`$ 是外层计算轮数；$`j`$ 是固定某套策略之后的内层评估轮数。算法可以在没有采集新轨迹的情况下反复使用同一份已知模型。

### 0.1 两个算子，一套记号

给候选表 $`u`$，先定义动作的一步评分：

```math
q_u(s,a)=\bar r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)u(s').
```

然后定义：

```math
(T_\pi u)(s)=\sum_a\pi(a\mid s)q_u(s,a),
\qquad
(T_*u)(s)=\max_a q_u(s,a).
```

前者按固定策略平均动作，后者挑最高分。若 $`u=v_\pi`$，有 $`T_\pi u=u`$；若 $`u=v_*`$，有 $`T_*u=u`$。**“输入一张表更新一次”与“找到更新后不再变化的表”是两件事。**

记 $`\operatorname{Greedy}(u)`$ 为根据 $`q_u`$ 逐状态选最高评分动作的一套确定性策略。有并列时需要约定如何选，但任一最大化动作都满足：

```math
T_{\operatorname{Greedy}(u)}u=T_*u.
```

只有当前输入恰好是 $`v_*`$，才能直接从这句话认定该贪心策略最优。

## 1. 贯穿三种算法的工作区

沿用之前的两状态持续式任务，折扣因子取 $`\gamma=0.5`$。

| 状态 | 动作 | 奖励 | 下一状态 |
| --- | --- | ---: | --- |
| A | 工作 | $`1`$ | A |
| A | 去 B | $`0`$ | B |
| B | 工作 | $`4`$ | B |
| B | 去 A | $`0`$ | A |

每个动作占一步，两个状态都不终止。对任意表 $`u=(u(A),u(B))`$，四个评分为：

```math
\begin{aligned}
q_u(A,\text{工作})&=1+0.5u(A),&
q_u(A,\text{去 B})&=0.5u(B),\\
q_u(B,\text{工作})&=4+0.5u(B),&
q_u(B,\text{去 A})&=0.5u(A).
\end{aligned}
```

后面每个数都从这四行得到。上一课已验证最优结果是 $`v_*=(4,8)`$，最优策略是“A 去 B，B 工作”；现在暂把这个答案遮住，检查不同算法如何找到它。

## 2. 值迭代：对最优方程反复做一次更新

### 2.1 一轮的计算顺序

从任意有限表 $`u_0`$ 出发，重复：

```math
\boxed{u_{k+1}=T_*u_k.}
```

也可以拆成两个动作：

```math
\pi_{k+1}=\operatorname{Greedy}(u_k),
\qquad
u_{k+1}=T_{\pi_{k+1}}u_k.
```

先根据旧表选策略，再用该策略更新一次。这一步并没有求解 $`v_{\pi_{k+1}}=T_{\pi_{k+1}}v_{\pi_{k+1}}`$；右侧用的仍是旧估计 $`u_k`$。

同步更新的流程可以写成：

```text
给定旧表 u
对每个状态 s：
    用同一张旧表 u 计算全部动作评分 q_u(s,a)
    把最高评分写入另一张新表 next[s]
    记录一个取得最高评分的动作
整张新表写完后，统一用 next 替换 u
```

如果算完 A 就立刻覆盖旧值，随后算 B 又使用新的 A，便是另一种更新次序，不再对应下面的同步迭代表。它可能仍是有效的动态规划变体，但比较数值时必须说明规则。

### 2.2 从全零开始逐轮计算

| 旧表 $`u_k`$ | A 的两个评分：工作、去 B | B 的两个评分：工作、去 A | 新表 $`u_{k+1}`$ |
| --- | --- | --- | --- |
| $`(0,0)`$ | $`1,0`$ | $`4,0`$ | $`(1,4)`$ |
| $`(1,4)`$ | $`1.5,2`$ | $`6,0.5`$ | $`(2,6)`$ |
| $`(2,6)`$ | $`2,3`$ | $`7,1`$ | $`(3,7)`$ |
| $`(3,7)`$ | $`2.5,3.5`$ | $`7.5,1.5`$ | $`(3.5,7.5)`$ |

第一轮还看不到去 B 后持续工作的收益，因此选出“A 工作，B 工作”。第二轮通过 $`u_1(B)=4`$，A 已经看见去 B 的价值，选出的动作就与最优策略一致了。

但第二轮的新表 $`(2,6)`$ 还不是最优价值。**动作已经选对，数值仍可能需要继续计算。** 本例后续误差逐轮缩小，最终才到 $`(4,8)`$。

从零初始化还有一个解释：$`u_k`$ 等于只计算未来 $`k`$ 步奖励、剩余尾部记为零时的最优价值。这个有限时域问题的决策通常依赖剩余步数，不能据此认定 $`u_k`$ 是某套无限时域平稳策略的准确价值。

### 2.3 为什么从不同初值出发仍能到同一个结果

第 3 课已证明：

```math
\|T_*u-T_*w\|_\infty\leq\gamma\|u-w\|_\infty.
```

将 $`w=v_*`$ 代入：

```math
\|u_k-v_*\|_\infty\leq\gamma^k\|u_0-v_*\|_\infty.
```

初值影响早期动作、数值和计算量，有限初值不会改变本设定下的极限。全零方便，但未必是价值的下界；如果任务只有负奖励，零反而可能偏高。想看全零与全十的并排计算，可读[初值怎么选](/posts/value-iteration-initialization/)。

### 2.4 停止时，究竟保证了哪个量

对当前表 $`u`$ 计算最优贝尔曼残差：

```math
\delta=\|T_*u-u\|_\infty.
```

它能给出当前表的误差界：

```math
\boxed{\|u-v_*\|_\infty\leq\frac{\delta}{1-\gamma}.}
```

若要求价值误差不超过 $`\varepsilon_v`$，令 $`\delta\leq(1-\gamma)\varepsilon_v`$ 是一个充分停止条件。实现时要明确返回的是计算残差时的旧表，还是更新后的新表，避免阈值与输出对象对不上。

近似价值表的误差还会影响动作。令 $`\pi=\operatorname{Greedy}(u)`$，由 $`T_\pi u=T_*u`$ 和两个算子的压缩性质，可得一个通用的保守界：

```math
\|v_*-v_\pi\|_\infty
\leq\frac{2\gamma}{1-\gamma}\|u-v_*\|_\infty
\leq\frac{2\gamma\delta}{(1-\gamma)^2}.
```

第一个不等式来自在 $`v_*-v_\pi=T_*v_*-T_\pi v_\pi`$ 中插入 $`T_*u=T_\pi u`$，再把 $`\gamma\|v_*-v_\pi\|_\infty`$ 移到左侧。这个界可能很松，但提醒我：**“表变化不大”与“执行这套策略的损失不大”需要数学联系，不能只凭目测替代。** $`\gamma=0`$ 时直接选一步最大期望奖励即可。

## 3. 策略迭代：先把一套策略算清，再改善它

### 3.1 外层改策略，内层算价值

第 $`k`$ 轮有两步。

先评估当前策略：

```math
v_{\pi_k}=T_{\pi_k}v_{\pi_k},
\qquad
(I-\gamma P_{\pi_k})v_{\pi_k}=r_{\pi_k}.
```

再改善策略：

```math
\boxed{\pi_{k+1}=\operatorname{Greedy}(v_{\pi_k}).}
```

小规模任务可以解线性方程组。也可以固定 $`\pi_k`$，从某张表 $`w_0`$ 开始反复计算 $`w_{j+1}=T_{\pi_k}w_j`$。理论上的精确评估指拿到方程准确解；数值实现通常按残差控制评估误差，而非真的运行无限次。

这里 $`j`$ 增加时策略不变；评估结束后 $`k`$ 才增加、策略才可能改变。把两层循环混在一起，就容易把策略迭代写成值迭代。

### 3.2 在同一工作区中走一遍

初始策略取“A 工作，B 工作”。先解：

```math
v_{\pi_0}(A)=1+0.5v_{\pi_0}(A)
\quad\Rightarrow\quad v_{\pi_0}(A)=2,
```

```math
v_{\pi_0}(B)=4+0.5v_{\pi_0}(B)
\quad\Rightarrow\quad v_{\pi_0}(B)=8.
```

将解出的 $`(2,8)`$ 用于动作比较：

| 状态 | 工作评分 | 移动评分 | 改善后的动作 |
| --- | --- | --- | --- |
| A | $`1+0.5\times2=2`$ | $`0.5\times8=4`$ | 去 B |
| B | $`4+0.5\times8=8`$ | $`0.5\times2=1`$ | 工作 |

得到 $`\pi_1`$：“A 去 B，B 工作”。再评估它：

```math
v_{\pi_1}(B)=8,
\qquad
v_{\pi_1}(A)=0.5\times8=4.
```

用 $`(4,8)`$ 再比较，A 的两个评分是 $`3,4`$，B 是 $`8,2`$，策略保持不变，可以停止。注意：刚选出 $`\pi_1`$ 时，手里的旧价值仍是 $`(2,8)`$；要报告 $`\pi_1`$ 的准确表现，需要再做评估。

### 3.3 为什么“只看一步”改善会提高长期表现

改善是根据准确的旧策略价值做的。令 $`\pi'=\operatorname{Greedy}(v_\pi)`$，则：

```math
T_{\pi'}v_\pi=T_*v_\pi\geq T_\pi v_\pi=v_\pi.
```

最优评分不小于旧策略的平均评分。又因为转移概率非负，$`T_{\pi'}`$ 保持逐状态的大小关系，所以反复应用同一新策略有：

```math
v_\pi\leq T_{\pi'}v_\pi\leq T_{\pi'}^2v_\pi
\leq\cdots\longrightarrow v_{\pi'}.
```

因此 $`v_{\pi'}\geq v_\pi`$。一步改善中的“未来”已经包含旧策略的整个长期价值；将这种改善在每一步重复执行，就形成长期不变差的保证。它不是只比较眼前奖励。

### 3.4 为什么策略不再改善时就最优

若准确评估后，新策略与旧策略相同，旧策略已经对自己的价值贪心：

```math
v_\pi=T_\pi v_\pi=T_*v_\pi.
```

于是它同时满足最优方程；该方程的唯一解是 $`v_*`$，所以 $`v_\pi=v_*`$。

有限状态、有限动作下，确定性策略的总数有限。若规定**旧动作已并列最大时保留旧动作，只在有严格改善时切换**，精确策略迭代不会为了相同价值反复切换动作；每次真正修改都会在至少一个状态带来严格改善，因此最终在有限次策略改善后结束。

这个停止结论依赖准确评估。若评估误差较大，某轮看起来动作没变，不足以证明最优；需要检查最优残差，或继续提高评估精度。计算中用“数值几乎相等”代替精确相等时，也要说明容差。

## 4. 截断策略迭代：改善后，到底评估几轮

前两种方法的区别可以压缩到一个问题：选出新策略后，是只更新一次价值，还是一直评估到准确？截断策略迭代允许停在中间。

### 4.1 用一个一致的计数约定表达三种方法

以下采用“先贪心选策略，再评估”的顺序，便于与值迭代逐项对应：

```math
\pi_{k+1}=\operatorname{Greedy}(u_k),\qquad w_0=u_k,
```

```math
w_{j+1}=T_{\pi_{k+1}}w_j,\quad j=0,\ldots,m-1,
\qquad
\boxed{u_{k+1}=w_m=T_{\pi_{k+1}}^m u_k.}
```

$`m`$ 是这一轮固定策略后的评估次数。内层 $`m`$ 次里不能重新做动作最大化，否则每一步都重新改善策略，就变成了连续执行 $`m`$ 轮值迭代。

| 评估深度 | 结果 |
| --- | --- |
| $`m=1`$ | $`u_{k+1}=T_*u_k`$，就是值迭代 |
| 固定有限 $`m>1`$ | 截断策略迭代；中间表一般还不是准确策略价值 |
| 将新策略评估到准确 | 下一张表为 $`v_{\pi_{k+1}}`$，接回精确策略迭代 |

教材也可写成“先评估已有策略，再改善”的顺序，两者主要是起点与下标的安排不同。说“值迭代是评估一轮的策略迭代”时，必须连同**新策略根据哪张表选择、评估从哪张表开始**一起说明。任意给定 $`\pi_0`$ 后先评估一轮，初始那一步不一定等于 $`T_*u_0`$。

### 4.2 用 $`m=2`$ 看见中间地带

仍从 $`u_0=(0,0)`$ 开始。

| 外层轮次 | 用旧表选出的策略 | 评估第 1 轮 | 评估第 2 轮，即新表 |
| --- | --- | --- | --- |
| 1 | A 工作，B 工作 | $`(1,4)`$ | $`(1.5,6)`$ |
| 2 | A 去 B，B 工作 | $`(3,7)`$ | $`(3.5,7.5)`$ |
| 3 | A 去 B，B 工作 | $`(3.75,7.75)`$ | $`(3.875,7.875)`$ |

最关键的是第一轮的 $`(1.5,6)`$。此时评估第二次仍固定“A 工作，B 工作”，所以 A 得到 $`1+0.5\times1=1.5`$；如果在这里重新比较“去 B”的 $`0.5\times4=2`$ 并选它，就已经违反了固定两轮策略的约定。

到第二轮外层，才使用 $`(1.5,6)`$ 比较动作。A 工作评分为 $`1.75`$，去 B 评分为 $`3`$，这时才切换到去 B。

这个例子也解释为什么不能只按“外层轮数”宣布某算法更快：三轮截断迭代已做了六次价值更新；三轮值迭代只做了三次。一次策略评估与一次动作搜索的开销也不同。

### 4.3 一条可直接看清的收敛路线

一般截断算法的分析比精确 PI 更细。这里记录一组容易验证的充分条件，避免把“只评估几次也行”当成无条件经验：精确表格运算、上述贪心后评估的顺序、固定整数 $`m\geq1`$，并从满足 $`u_0\leq T_*u_0`$ 的下界开始。

例如若所有一步奖励不小于 $`r_{\min}`$，可取每个状态都为：

```math
u_0(s)=\frac{r_{\min}}{1-\gamma}.
```

这个值是任意策略回报的下界，也满足 $`u_0\leq T_*u_0`$。若当前有 $`u_k\leq T_*u_k`$，选择贪心策略后：

```math
u_k\leq T_{\pi_{k+1}}u_k
\leq T_{\pi_{k+1}}^2u_k
\leq\cdots\leq u_{k+1}\leq v_*.
```

同时 $`T_*u_{k+1}\geq T_{\pi_{k+1}}u_{k+1}\geq u_{k+1}`$，所以这个性质传到下一轮。再记从相同初值开始的普通值迭代为 $`z_{k+1}=T_*z_k`$，由单调性归纳可得：

```math
z_k\leq u_k\leq v_*.
```

$`z_k`$ 已知收敛到 $`v_*`$，夹在中间的 $`u_k`$ 因而也收敛到 $`v_*`$。这是一个充分条件下的完整解释；并不意味着任意初值都必须单调，也不能把这条表格结论推广成带采样噪声或神经网络近似时的自动保证。

### 4.4 从相同起点比较，差异才有明确含义

再取一套初始策略“A 工作，B 去 A”。它的准确价值是 $`(2,1)`$：在 A 反复工作得 $`2`$，从 B 先无奖励地去 A，所以只得 $`0.5\times2=1`$。

让三种算法都从这张准确表出发。按 $`(2,1)`$ 做第一次贪心选择，A 仍选工作，B 改选工作。接下来差别完全落在对这套新策略评估多深：

| 相同起点 $`(2,1)`$，相同新策略“都工作” | 得到的表 |
| --- | --- |
| 只评估一轮 | $`(2,4.5)`$ |
| 连续评估两轮 | $`(2,6.25)`$ |
| 评估到准确 | $`(2,8)`$ |

例如 B 的第二次更新是 $`4+0.5\times4.5=6.25`$。A 的数值始终为 $`2`$，因为它在新策略下继续工作，本来就已经评估准确。这几张表的差别来自尚未算完的新策略长期收益，不能解释成机器人真的采取了不同动作、获得了不同实验回报。

这个对照也揭示教材比较图背后的前提：初始表来自同一套准确旧策略，改善后的策略相同，评估沿同一个方向继续进行。任意换一张初值、换更新次序，再直接比较曲线高低，便失去了这组逐项对应关系。实际报告算法效率时，还应把“寻找一个足够好的策略”和“把价值估计到很高精度”区分为两个目标。

## 5. 写成程序时容易把算法改掉的地方

| 检查项 | 应确认的含义 |
| --- | --- |
| 旧表与新表 | 同步更新时，每个状态都读同一版本的旧表 |
| 内外层循环 | 内层评估保持策略固定，外层才改善动作 |
| 终止状态 | 终止后价值为零；进入终点的奖励只算一次 |
| 动作平局 | 精确 PI 优先保留旧的最大化动作；实现记录数值容差 |
| 停止对象 | 评估残差针对 $`T_\pi`$；最优残差针对 $`T_*`$，两者不能替代 |
| 输出策略 | 明确它是对最终返回的哪张表做的贪心选择 |
| 统计成本 | 同时记录动作搜索、价值更新次数和运行时间 |

例如一张表已经满足某套很差策略的 $`T_\pi u=u`$，其评估残差为零，却可能有很大的 $`T_*u-u`$。这说明“这套策略算准了”，不说明“这套策略最优了”。

在有限精度下，近似评估也会把两个很接近的动作颠倒。若已知评估误差至多为 $`\eta`$，每个动作评分的误差至多为 $`\gamma\eta`$；两个评分差的误差可达 $`2\gamma\eta`$。当动作分差很小，继续精化价值比急着切换动作更有依据。

## 6. 怎样理解三种方法的计算取舍

值迭代每次动作搜索后只更新一遍，结构简单，但远处的价值信息可能需要多轮才能传播。精确策略迭代把当前策略的长期后果算清再改善，往往需要较少的策略改善轮次，但评估本身可能昂贵。截断方法在两者之间分配计算量。

这里的“往往”需要保留：状态数、动作数、转移稀疏性、折扣因子、初值与精度都影响实际成本。不能从示意图上的曲线先后，推出某算法在所有任务里都耗时更短。大规模问题中直接形成矩阵逆通常也不是好实现，求解线性方程或利用稀疏结构更合适。

另一种共同视角叫广义策略迭代：**价值估计影响动作选择，新的动作选择又改变需要估计的价值。** 它描述评估与改善相互作用的结构，不是要求每种算法都具有完全相同的双层循环。

## 7. 从已知模型，走向用经历学习

这三种方法都需要把环境可能产生的结果求平均。在机器人控制里，高维状态、接触和扰动让完整转移表很难获得；即使有仿真器，能运行仿真也不等于能枚举每个状态动作的精确转移分布。

下一步自然是：既然没法直接算出期望，能否用采集到的回报估计价值？[第 5 课：蒙特卡洛方法](/posts/rl-math-05-monte-carlo/)沿着策略评估与改善继续走，只是把模型求和换成完整轨迹的样本平均。[第 6 课](/posts/rl-math-06-stochastic-approximation/)再解释如何递推更新、如何处理采样噪声。

回看本课，最值得保留的对应关系是：**值迭代对最优方程更新；策略迭代把给定策略的方程解准再改善；截断策略迭代控制每次改善之间的评估深度。** 识别算法时先问更新式里的策略是否固定，再问右侧价值是准确值还是近似值。
