# 《强化学习的数学原理》学习笔记 02：贝尔曼公式

> **对应课程**：西湖大学赵世钰《强化学习的数学原理》，第 2 课「贝尔曼公式」。  
> **对应分节**：动机、状态价值、贝尔曼公式推导、矩阵形式与求解、动作价值。  
> **教材对应**：*Mathematical Foundations of Reinforcement Learning*，Chapter 2: State Values and Bellman Equation，重点为 §2.3–2.8。  
> **整理日期**：2026-10-23。

这份笔记沿着「如何评价一套给定的行为规则」展开，依据作者官方教材和课程结构重新组织解释。文中的 A、B 工作区及其随机转移变体是自编辅助算例，用于把公式逐项算出来；不是课程原图的转录。本文保留必要推导、数值计算和容易混淆的地方，方便学习时反复回看。

第一课建立了状态、动作、奖励、回报与策略的语言。本课开始把它们连成一个能够求解的问题：**策略已经给定时，从不同状态出发，长期表现究竟是多少？**

## 0. 先固定讨论范围与符号

本课主要讨论有限状态、有限动作的平稳 MDP：环境的概率规则不随时间改变，策略也是固定的平稳马尔可夫策略 $`\pi(a\mid s)`$。即时奖励有界，折扣因子满足 $`0\leq\gamma<1`$。这些条件保证无限期折扣回报存在，并支持后面的唯一解与收敛结论。

为便于写出求和，本篇先用离散奖励表示公式；若奖励连续，将有关奖励的求和改为积分，条件期望的定义与推导结构不变。有限状态、有限动作并不自动意味着奖励只能取有限个数值。

沿用第一课的下标约定：在 $`S_t`$ 选择 $`A_t`$，环境产生 $`S_{t+1}`$ 和 $`R_{t+1}`$。

| 符号 | 含义 |
| --- | --- |
| $`S_t,A_t,R_{t+1}`$ | 状态、动作、奖励随机变量 |
| $`s,a,r`$ | 对应的具体取值 |
| $`G_t`$ | 从时刻 $`t`$ 开始的折扣回报 |
| $`p(s'\mid s,a)`$ | 给定当前状态、动作后的转移概率 |
| $`\bar r(s,a)`$ | 给定状态、动作的一步期望奖励 |
| $`v_\pi(s)`$ | 固定策略下的状态价值 |
| $`q_\pi(s,a)`$ | 第一步指定动作、之后执行策略的动作价值 |

本文使用教材的下标写法 $`v_\pi,q_\pi`$；其他资料中的 $`V^\pi,Q^\pi`$ 通常表达相同概念。这里的「价值」表示**期望折扣累计回报**，不能把它理解成某一步的奖励，也不能和平均奖励目标中的长期每步平均收益混为一谈。

## 1. 为什么仅记录一条轨迹的回报还不够

沿一条已经发生的轨迹，可以计算：

```math
G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots
=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1}.
```

但在随机策略或随机环境中，即使从同一状态出发，重复执行同一策略，也可能获得不同轨迹、不同回报。单次结果只能描述这次经历，不能直接代表这套行为规则的长期表现。

因此引入条件期望：

```math
\boxed{v_\pi(s)=\mathbb E_\pi[G_t\mid S_t=s].}
```

这个定义同时固定了两件事：从状态 $`s`$ 出发；随后始终按照策略 $`\pi`$ 行动。期望需要覆盖策略抽样动作、环境转移以及奖励的随机性。实际估计它时可以重复采样；有完整环境模型时也可以直接求解，本课主要学习后一条路线。

**对同一状态换一套策略，价值可能改变；对同一策略换一个起点，价值也可能改变。** 所以状态价值的下标和自变量都不能省略理解。

平稳无限时域设定下，价值不显式依赖 $`t`$。如果任务只剩三步与只剩一步的价值不同，就需要带时间下标的有限时域价值，或把剩余时间纳入状态，不能直接套用一张不变的价值表。

### 1.1 贯穿本课的自编工作区

设机器人有 A、B 两个工作区，规则如下，所有转移暂时都是确定性的：

| 当前状态 | 动作 | 即时奖励 | 下一状态 |
| --- | --- | --- | --- |
| A | 普通工作 | $`+1`$ | A |
| A | 去 B | $`0`$ | B |
| B | 高收益工作 | $`+4`$ | B |
| B | 去 A | $`0`$ | A |

一次工作或移动都占用一步，取 $`\gamma=0.5`$。这是持续式任务，B 不是终止状态，可以一直工作。

先评估下面这套策略：

```math
\pi(\mathrm{work}\mid A)=\frac12,\qquad
\pi(\mathrm{goB}\mid A)=\frac12,\qquad
\pi(\mathrm{work}\mid B)=1.
```

意思是在 A 每一步重新各以一半概率选择工作或去 B，到 B 后始终工作。**这里的随机性来自策略，环境执行某个指定动作的结果仍然确定。** 后文会把环境随机性另加进来，检查两类概率在公式中各出现在哪里。

## 2. 贝尔曼关系的起点：回报可以拆成一步与后续

从定义直接提取第一项：

```math
\begin{aligned}
G_t
&=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots\\
&=R_{t+1}+\gamma\left(R_{t+2}+\gamma R_{t+3}+\cdots\right)\\
&=R_{t+1}+\gamma G_{t+1}.
\end{aligned}
```

这是**同一条轨迹上的回报递推关系**，还没有取平均，也没有选择最优动作。第一笔奖励 $`R_{t+1}`$ 不乘折扣；从下一时刻看未来的整段回报 $`G_{t+1}`$，需要折扣一次。

对两边取「当前状态为 $`s`$」时的条件期望：

```math
\begin{aligned}
v_\pi(s)
&=\mathbb E_\pi[R_{t+1}+\gamma G_{t+1}\mid S_t=s]\\
&=\mathbb E_\pi[R_{t+1}\mid S_t=s]
+\gamma\mathbb E_\pi[G_{t+1}\mid S_t=s].
\end{aligned}
```

这一步只用了期望的线性性质，**没有要求即时奖励与后续回报独立**。下面分别把两项展开。

## 3. 按动作、奖励和下一状态逐层展开期望

### 3.1 即时奖励项：先考虑策略会选哪个动作

当前状态已知，但动作仍按策略随机选取。由全期望公式：

```math
\mathbb E_\pi[R_{t+1}\mid S_t=s]
=\sum_{a\in\mathcal A(s)}\pi(a\mid s)
\mathbb E[R_{t+1}\mid S_t=s,A_t=a].
```

把最后的条件期望定义为：

```math
\bar r(s,a)
=\mathbb E[R_{t+1}\mid S_t=s,A_t=a]
=\sum_r p(r\mid s,a)r.
```

于是即时奖励项为 $`\sum_a\pi(a\mid s)\bar r(s,a)`$。求和的顺序有明确含义：对给定动作求环境奖励的平均，再对策略可能选择的动作求平均。

### 3.2 后续回报项：根据下一状态接上同一策略的价值

先给定当前动作，再枚举下一状态：

```math
\begin{aligned}
\mathbb E_\pi[G_{t+1}\mid S_t=s]
&=\sum_a\pi(a\mid s)
\sum_{s'}p(s'\mid s,a)\\
&\qquad\cdot\mathbb E_\pi[G_{t+1}\mid S_t=s,A_t=a,S_{t+1}=s'].
\end{aligned}
```

由于状态满足马尔可夫性质，且下一步起仍然执行相同的平稳马尔可夫策略，到了 $`s'`$ 以后，不需要额外记住先前如何到达。因此：

```math
\mathbb E_\pi[G_{t+1}\mid S_t=s,A_t=a,S_{t+1}=s']
=v_\pi(s').
```

所以：

```math
\mathbb E_\pi[G_{t+1}\mid S_t=s]
=\sum_a\pi(a\mid s)\sum_{s'}p(s'\mid s,a)v_\pi(s').
```

**这一步才使用了状态的充分性。** 如果状态漏掉了会影响未来的电量、接触模式或任务阶段，相同的 $`s'`$ 未必具有相同的后续分布，这个替换就需要重新检查。

### 3.3 合起来：固定策略的贝尔曼公式

```math
\boxed{
v_\pi(s)
=\sum_{a\in\mathcal A(s)}\pi(a\mid s)
\left[
\bar r(s,a)+\gamma\sum_{s'\in\mathcal S}
p(s'\mid s,a)v_\pi(s')
\right].
}
```

读这个式子时，可以依次对照四件事：

| 公式部分 | 在计算什么 |
| --- | --- |
| $`\pi(a\mid s)`$ | 当前策略选择这个动作的概率 |
| $`\bar r(s,a)`$ | 执行当前动作的一步期望奖励 |
| $`p(s'\mid s,a)v_\pi(s')`$ | 按环境转移概率加权的后继状态价值 |
| 外层动作求和 | 把当前策略所有可能选择综合起来 |

公式对每个状态都成立。把所有状态的式子放在一起，得到的是**一组联立方程**，并非拿一个未知数孤立地去计算另一个未知数。右边出现未知的下一状态价值，是各状态长期表现相互关联的数学表达。

### 3.4 奖励依赖下一状态时，是否仍然成立

成立。前面的 $`\bar r(s,a)`$ 已经对奖励随机性求了平均，不能把它误读成「奖励只能由当前状态、动作决定」。更一般的联合写法是：

```math
\boxed{
v_\pi(s)=\sum_a\pi(a\mid s)
\sum_{s',r}p(s',r\mid s,a)
\left[r+\gamma v_\pi(s')\right].
}
```

其中 $`p(s',r\mid s,a)`$ 同时描述后继状态和奖励。它允许「成功到达 B 得 0，失败留在 A 得 −1」这类关联。把联合概率分别边缘化，就回到前面的表达：

```math
\bar r(s,a)=\sum_{s',r}p(s',r\mid s,a)r,\qquad
p(s'\mid s,a)=\sum_r p(s',r\mid s,a).
```

**拆成即时奖励期望与后继价值期望，不等于假设奖励、转移彼此独立。** 这里能拆开是因为二者相加，期望可以逐项计算。

## 4. 把工作区算例完整解出来

先回到第 1 节的基准环境，继续固定随机策略。在 B 始终工作，因此：

```math
v_\pi(B)=4+0.5v_\pi(B)
\quad\Longrightarrow\quad v_\pi(B)=8.
```

在 A，有两种策略选择：一半概率工作后仍在 A；一半概率去 B。于是：

```math
\begin{aligned}
v_\pi(A)
&=\frac12\left[1+0.5v_\pi(A)\right]
+\frac12\left[0+0.5v_\pi(B)\right]\\
&=0.5+0.25v_\pi(A)+0.25\times8.
\end{aligned}
```

移项：

```math
0.75v_\pi(A)=2.5
\quad\Longrightarrow\quad
\boxed{v_\pi(A)=\frac{10}{3},\quad v_\pi(B)=8.}
```

可以用另两套策略检查这个结果：

| 策略 | $`v(A)`$ | $`v(B)`$ |
| --- | --- | --- |
| A 一直普通工作；B 一直高收益工作 | $`1/(1-0.5)=2`$ | $`8`$ |
| A 各以一半概率工作或去 B；B 一直工作 | $`10/3\approx3.3333`$ | $`8`$ |
| A 立即去 B；B 一直工作 | $`0+0.5\times8=4`$ | $`8`$ |

随机策略有时延迟进入高收益区，所以 A 的价值介于前两种确定性选择之间。**这里算出 $`10/3`$，并不代表 A 所能达到的最大价值；它只表示当前这套给定策略的表现。** 评价与优化是两个问题，第 3 课才会系统引入最优价值。

### 4.1 从整条轨迹再核对一次平均的含义

设机器人在 A 连续工作 $`n`$ 次，然后第一次去 B。因为在 A 每一步重新按策略抽样，这种情况的概率是 $`(1/2)^{n+1}`$。去 B 的那一步奖励为 0，到 B 后的后续价值为 8，因此这一条轨迹的折扣回报为：

```math
g_n=\sum_{i=0}^{n-1}0.5^i+0.5^{n+1}\times8
=2+2\times0.5^n,\qquad n=0,1,2,\ldots.
```

当 $`n=0`$ 时，前面的空和为 0。几个具体结果是：

| 去 B 以前在 A 工作的次数 | 这类轨迹的概率 | 从 A 出发的回报 |
| --- | --- | --- |
| 0 次 | $`1/2`$ | $`4`$ |
| 1 次 | $`1/4`$ | $`3`$ |
| 2 次 | $`1/8`$ | $`2.5`$ |
| 3 次 | $`1/16`$ | $`2.25`$ |

将所有可能的工作次数加权：

```math
\begin{aligned}
v_\pi(A)
&=\sum_{n=0}^{\infty}\left(\frac12\right)^{n+1}
\left[2+2\left(\frac12\right)^n\right]\\
&=2\sum_{n=0}^{\infty}\left(\frac12\right)^{n+1}
+\sum_{n=0}^{\infty}\left(\frac14\right)^n\\
&=2+\frac43=\frac{10}{3}.
\end{aligned}
```

这说明价值 $`10/3`$ 是轨迹回报的平均，未必等于某次运行的具体回报。完全不离开 A 的事件概率为零，不影响上述期望。

还有一个细节：当前策略并不是「出发前只抛一次硬币，决定永远在 A 工作或立刻去 B」。后者相当于在两套完整行为规则中先选一套，其平均回报为 $`0.5\times2+0.5\times4=3`$，与本例不同。**每次到达状态都按同一动作概率重新决策**，和**先随机选择一整套长期方案**，是不同的决策过程。理解这一点，再看贝尔曼公式里的动作求和就更明确了。

## 5. 矩阵形式：把所有状态的方程放在一起

### 5.1 先将动作选择平均进模型

定义策略下的一步期望奖励和转移概率：

```math
r_\pi(s)=\sum_a\pi(a\mid s)\bar r(s,a),\qquad
p_\pi(s'\mid s)=\sum_a\pi(a\mid s)p(s'\mid s,a).
```

固定状态顺序 $`s_1,\ldots,s_n`$，组成列向量与矩阵：

```math
\mathbf v_\pi=
\begin{pmatrix}v_\pi(s_1)\\\vdots\\v_\pi(s_n)\end{pmatrix},
\quad
\mathbf r_\pi=
\begin{pmatrix}r_\pi(s_1)\\\vdots\\r_\pi(s_n)\end{pmatrix},
\quad
[P_\pi]_{ij}=p_\pi(s_j\mid s_i).
```

**行表示当前状态，列表示下一状态。** 因而每一行非负且总和为 1，$`P_\pi`$ 是行随机矩阵。一次矩阵乘法 $`P_\pi\mathbf v`$ 就在所有当前状态下分别计算了「下一状态价值的平均」。

联立方程写成：

```math
\boxed{\mathbf v_\pi=\mathbf r_\pi+\gamma P_\pi\mathbf v_\pi.}
```

在工作区算例中，以 A、B 排序：

```math
\mathbf r_\pi=\begin{pmatrix}0.5\\4\end{pmatrix},
\qquad
P_\pi=\begin{pmatrix}0.5&0.5\\0&1\end{pmatrix}.
```

这里 $`r_\pi(A)=0.5\times1+0.5\times0=0.5`$。不要把 A 的两种动作分别当成两行；$`P_\pi`$ 的每一行对应一个状态，动作已经按策略求了平均。

### 5.2 闭式解与本例的具体矩阵

移项得到：

```math
(I-\gamma P_\pi)\mathbf v_\pi=\mathbf r_\pi,
\qquad
\boxed{\mathbf v_\pi=(I-\gamma P_\pi)^{-1}\mathbf r_\pi.}
```

本例为：

```math
\begin{pmatrix}0.75&-0.25\\0&0.5\end{pmatrix}
\begin{pmatrix}v_\pi(A)\\v_\pi(B)\end{pmatrix}
=\begin{pmatrix}0.5\\4\end{pmatrix}.
```

其逆矩阵与解为：

```math
(I-0.5P_\pi)^{-1}
=\begin{pmatrix}4/3&2/3\\0&2\end{pmatrix},
\qquad
\mathbf v_\pi
=\begin{pmatrix}4/3&2/3\\0&2\end{pmatrix}
\begin{pmatrix}0.5\\4\end{pmatrix}
=\begin{pmatrix}10/3\\8\end{pmatrix}.
```

这与手算一致。实际编程通常直接求解线性方程组，而不显式形成逆矩阵；小例子写出逆矩阵，是为了看清数学关系。

### 5.3 为什么逆一定存在

关键条件是 $`\gamma<1`$，并非「任何形如 $`I-\gamma P`$ 的矩阵都可逆」。行随机矩阵在最大范数下满足 $`\|P_\pi\|_\infty=1`$，因此矩阵级数收敛：

```math
(I-\gamma P_\pi)^{-1}
=I+\gamma P_\pi+\gamma^2P_\pi^2+\cdots.
```

用 $`I-\gamma P_\pi`$ 乘有限部分和，结果是 $`I-\gamma^{m+1}P_\pi^{m+1}`$；后面这项在 $`m\to\infty`$ 时趋于零，所以级数确实给出了逆。

进一步：

```math
\mathbf v_\pi
=\mathbf r_\pi+\gamma P_\pi\mathbf r_\pi
+\gamma^2P_\pi^2\mathbf r_\pi+\cdots.
```

这又回到了回报的意义：第一项是当前一步平均奖励；第二项是转移一步后获得的平均奖励；后续依次类推。线性代数解和按时间累加的定义描述的是同一件事。

因为级数中的矩阵元素均非负，还能得到：在**固定相同 $`P_\pi`$ 和折扣因子**时，逐状态提高 $`\mathbf r_\pi`$，不会降低任何状态的价值。若策略或转移也变了，则需要重新比较完整方程，不能只看即时奖励向量。

## 6. 不求逆，也能迭代评估给定策略

取任意有限初始价值向量 $`\mathbf u_0`$，重复：

```math
\boxed{\mathbf u_{k+1}=\mathbf r_\pi+\gamma P_\pi\mathbf u_k.}
```

这里 $`k`$ 是计算轮数，不是机器人实际行动的时间 $`t`$。本节采用同步更新：一整轮所有新值都使用上一轮的旧值。

从全零出发，基准算例得到：

| 计算轮数 $`k`$ | $`u_k(A)`$ | $`u_k(B)`$ |
| --- | --- | --- |
| 0 | $`0`$ | $`0`$ |
| 1 | $`0.5`$ | $`4`$ |
| 2 | $`1.625`$ | $`6`$ |
| 3 | $`2.40625`$ | $`7`$ |
| 4 | $`2.8515625`$ | $`7.5`$ |
| 极限 | $`10/3`$ | $`8`$ |

例如第 2 轮的 A：

```math
u_2(A)=0.5+0.5\left[0.5\times0.5+0.5\times4\right]=1.625.
```

从全零开始时，$`\mathbf u_k`$ 还有一个直观解释：只计算未来 $`k`$ 步奖励、之后的尾部暂记为零，且这 $`k`$ 步始终执行给定策略。第一轮只看到当前一步；第二轮把下一步的期望收益也接进来。随着轮数增加，更远的奖励被纳入，才逐渐接近无限期的准确价值。

如果初值不是零，这种「只看 $`k`$ 步」的解释就需要带上尾值。具体而言：

```math
u_k(s)=\mathbb E_\pi\left[
\sum_{i=0}^{k-1}\gamma^iR_{t+i+1}
+\gamma^ku_0(S_{t+k})\;\middle|\;S_t=s
\right].
```

初值的影响被放到第 $`k`$ 步的末端，并乘以 $`\gamma^k`$。因此它既不是环境真的发放的一笔奖励，也不是算法要求机器人亲自执行的预热步骤，而是计算中对尚未展开的未来所采用的估计。

### 6.1 为什么会收敛到准确价值

令 $`\mathbf e_k=\mathbf u_k-\mathbf v_\pi`$。将准确方程与更新式相减：

```math
\mathbf e_{k+1}=\gamma P_\pi\mathbf e_k.
```

由于每行是概率平均，平均后的绝对误差不超过各状态的最大绝对误差：

```math
\|\mathbf e_{k+1}\|_\infty
\leq\gamma\|\mathbf e_k\|_\infty
\leq\gamma^{k+1}\|\mathbf e_0\|_\infty.
```

因此任意有限初值都会收敛到唯一的 $`\mathbf v_\pi`$。初值会影响中途数值和所需轮数，但不会改变本设定下的最终解。这里控制的是**最大范数误差**，不能未经证明就把同样的逐轮比例套用到其他范数或每个状态的单独误差上。

### 6.2 一个可计算的停止依据

设当前向量为 $`\mathbf u`$，计算其贝尔曼残差：

```math
\delta=\|\mathbf r_\pi+\gamma P_\pi\mathbf u-\mathbf u\|_\infty.
```

通过三角不等式和前面的压缩界，可以得到：

```math
\|\mathbf u-\mathbf v_\pi\|_\infty
\leq\frac{\delta}{1-\gamma}.
```

例如 $`\gamma=0.5`$，当前价值表更新一次的最大变化为 $`0.001`$，那么**这张当前表**距准确策略价值的最大误差不超过 $`0.002`$。折扣越接近 1，相同残差对应的误差界越宽，停止阈值需要更谨慎。

注意这叫**迭代策略评估**：整个计算过程中 $`\pi`$ 固定。第 4 课中的「值迭代」会每轮比较动作、直接逼近最优价值，两者的更新含义不同。

## 7. 动作价值：第一步如果指定动作，之后会怎样

状态价值把当前策略所有可能动作平均了。有时想单独比较某个动作，需要定义：

```math
\boxed{q_\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a].}
```

操作含义是：**当前第一步指定执行 $`a`$，从下一步起执行 $`\pi`$。** 对 $`\pi(a\mid s)=0`$ 的动作，也可用环境模型规定「强制执行一次」来定义该动作价值，不必把零概率事件的条件期望机械地当成普通比值。

从回报递推得到：

```math
\boxed{
q_\pi(s,a)=\bar r(s,a)
+\gamma\sum_{s'}p(s'\mid s,a)v_\pi(s').
}
```

当前动作已经指定，所以这里**没有对当前动作乘 $`\pi(a\mid s)`$**。接下来从 $`s'`$ 开始才恢复策略，其后果已经包含在 $`v_\pi(s')`$ 中。

反过来，按策略平均动作价值：

```math
\boxed{v_\pi(s)=\sum_a\pi(a\mid s)q_\pi(s,a).}
```

两式合起来，还能写出动作价值自身的贝尔曼关系：

```math
q_\pi(s,a)=\bar r(s,a)
+\gamma\sum_{s'}p(s'\mid s,a)
\sum_{a'}\pi(a'\mid s')q_\pi(s',a').
```

### 7.1 用刚才求出的价值计算所有动作

将 $`v_\pi(A)=10/3,v_\pi(B)=8`$ 代入：

| 状态动作对 | 计算 | 动作价值 |
| --- | --- | --- |
| A 普通工作 | $`1+0.5\times(10/3)`$ | $`8/3`$ |
| A 去 B | $`0+0.5\times8`$ | $`4`$ |
| B 高收益工作 | $`4+0.5\times8`$ | $`8`$ |
| B 去 A | $`0+0.5\times(10/3)`$ | $`5/3`$ |

再检查状态价值：

```math
v_\pi(A)=\frac12\cdot\frac83+\frac12\cdot4=\frac{10}{3},
\qquad
v_\pi(B)=1\times8=8.
```

在 A 工作的动作价值 $`8/3`$ 大于“一直留在 A 工作”的价值 $`2`$。原因是 $`q_\pi(A,\mathrm{work})`$ 只要求**第一步**工作，后面恢复随机策略，仍有机会进入 B。它不是把“工作”这个动作永久重复下去的价值。

因此，比较两个动作价值时，不能给每个动作悄悄配上一套不同的后续策略。例如，不能把「第一步去 B，后面采用最优行为」和「第一步工作，后面仍用当前随机策略」直接放在同一张 $`q_\pi`$ 表中。下标相同的 $`\pi`$ 规定了共同的后续行为，只有第一步动作的条件不同，比较才对应同一个定义。

此外 $`q_\pi(A,\mathrm{goB})>v_\pi(A)`$，提示当前策略在 A 还有改善空间。但不能把任意当前策略的 $`\max_a q_\pi(s,a)`$ 直接称为最优价值；那些动作评分的后续仍然受旧策略约束。怎样系统地建立最优价值，是下一课的问题。

## 8. 加入随机转移，再检查一次公式的每个概率

以下是独立变体，除了 A 的“去 B”动作外，其余规则与基准环境相同：

| A 执行“去 B”的结果 | 概率 | 下一状态 | 即时奖励 |
| --- | --- | --- | --- |
| 成功移动 | $`0.8`$ | B | $`0`$ |
| 移动失败 | $`0.2`$ | A | $`-1`$ |

策略仍是在 A 各一半选择工作与去 B，在 B 始终工作。于是：

```math
\bar r(A,\mathrm{goB})=0.8\times0+0.2\times(-1)=-0.2,
```

```math
r_\pi(A)=0.5\times1+0.5\times(-0.2)=0.4.
```

下一状态概率先由动作决定，再按策略平均：

```math
p_\pi(A\mid A)=0.5\times1+0.5\times0.2=0.6,
\qquad
p_\pi(B\mid A)=0.5\times0+0.5\times0.8=0.4.
```

新的矩阵、奖励向量为：

```math
P_\pi=\begin{pmatrix}0.6&0.4\\0&1\end{pmatrix},
\qquad
\mathbf r_\pi=\begin{pmatrix}0.4\\4\end{pmatrix}.
```

B 的价值仍为 8。在 A 联立：

```math
v_\pi(A)=0.4+0.5\left[0.6v_\pi(A)+0.4\times8\right]
=2+0.3v_\pi(A),
```

所以 $`v_\pi(A)=20/7\approx2.8571`$，比基准环境的 $`10/3`$ 更低。

也可以用联合结果直接算动作价值：

```math
\begin{aligned}
q_\pi(A,\mathrm{goB})
&=0.8\left[0+0.5\times8\right]
+0.2\left[-1+0.5\times\frac{20}{7}\right]\\
&=\frac{23}{7},\\
q_\pi(A,\mathrm{work})&=1+0.5\times\frac{20}{7}=\frac{17}{7}.
\end{aligned}
```

按当前策略平均，得到 $`\frac12\cdot\frac{23}{7}+\frac12\cdot\frac{17}{7}=\frac{20}{7}`$，两种算法再次一致。这个变体把**策略选动作的概率**、**动作导致不同结果的概率**以及**奖励与结果的关联**放在了各自正确的位置。

## 9. 终止、边界条件与容易混淆的地方

若任务在到达终点时真正结束，并且此后不再产生奖励，通常定义终止状态价值为 0。到达时的奖励计入那次转移的 $`R_{t+1}`$，不能既计入转移，又额外放进终止状态价值重复计算。

若用零奖励自环表示终止状态，则 $`v_\pi(s_T)=0+\gamma v_\pi(s_T)`$，在本课 $`\gamma<1`$ 条件下也得到 0。若只保留非终止状态，转移子矩阵的某些行和可以小于 1，因为剩余概率流向了终止状态，此时要相应解释矩阵。

本课工作区的 B 会持续产出奖励，因此 $`v_\pi(B)=8`$。若把“到 B 获得一次奖励后结束”设为另一个任务，就必须重新写转移与奖励，不能继续沿用本例数值。

| 容易混淆的说法 | 需要记住的区别 |
| --- | --- |
| 价值就是状态自身固定的分数 | 给定奖励规则和折扣后，价值仍依赖策略 |
| 公式右边出现未知价值，就无法计算 | 所有状态构成联立方程，可整体求解或迭代 |
| 取了期望就等于只看一步 | 期望中的回报包含整个未来，递推只压缩了表达 |
| $`q_\pi(s,a)`$ 表示永远执行动作 $`a`$ | 只固定第一步动作，之后按 $`\pi`$ 行动 |
| 价值表由迭代求出，就是值迭代算法 | 固定策略的迭代评估与最优值迭代需要区分 |
| 状态价值较高，单次轨迹一定更好 | 价值比较的是期望，具体随机轨迹可能相反 |
| 有了贝尔曼公式，就已经知道怎样最优行动 | 本课先评价给定策略；优化还需引入最优性 |

在机器人控制语境下，状态可包含姿态、速度与接触信息，动作可为力矩或目标关节角。$`\bar r(s,a)`$ 概括一步的跟踪、能耗、稳定性等奖励项；$`v_\pi(s')`$ 概括执行该控制策略后更长时间的表现。具体系统如何选状态、奖励和时间步长，会决定这个数学问题对应何种物理行为，不能只凭“即时奖励很高”判断后续稳定性。

## 10. 本课与下一课的连接

本课得到的主要关系是：

```math
v_\pi(s)=\sum_a\pi(a\mid s)q_\pi(s,a),
\qquad
q_\pi(s,a)=\bar r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v_\pi(s').
```

固定策略后，$`\mathbf r_\pi`$ 与 $`P_\pi`$ 固定，贝尔曼方程给出唯一的价值表。可以直接解线性方程，也可以按固定策略反复更新。上述结果回答的是“**这样一直做下去，长期值多少**”。

第 3 课「贝尔曼最优公式」会把问题推进到：在所有策略中，哪些状态价值能够同时达到最好？怎样从最优价值选出最优动作？本例中，$`(2,8)`$、$`(10/3,8)`$、$`(4,8)`$ 的比较正好提供了入口。
