## 0. 从“这套策略值多少”走向“哪套策略最好”

上一课的贝尔曼公式回答：**策略已经给定时，始终执行它的期望长期回报是多少？**

这一课要进一步回答：能否找到一套策略，使它从每个状态出发都至少和其他策略一样好？找到最优价值以后，又怎样恢复具体动作？

两类问题的表达分别是：

```math
v_\pi(s)
=\sum_a\pi(a\mid s)
\left[\bar r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v_\pi(s')\right],
```

```math
v_*(s)
=\max_a
\left[\bar r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v_*(s')\right].
```

前者的动作由给定策略加权，后者在动作中寻找最优选择。但这个 $`\max`$ 并不只比较即时奖励；它比较的是**当前一步奖励，加上从下一状态开始的最优后续价值**。

这篇笔记主要讨论有限状态、每个状态有有限个可行动作、奖励有界的马尔可夫决策过程，并假设：

```math
0\leq\gamma<1.
```

策略可以按状态自由选择动作或动作分布。若把策略限制为某个共享参数的神经网络，后文逐状态独立选最优动作的结论不能直接照搬。一般连续空间、平均奖励与未折扣问题也需要额外条件。

## 1. 怎样定义“更好”和“最优”

### 1.1 价值表的比较是逐状态的

设两套策略分别是 $`\pi_1`$、$`\pi_2`$。如果：

```math
v_{\pi_1}(s)\geq v_{\pi_2}(s),
\qquad \text{对所有 }s\in\mathcal S,
```

就说 $`\pi_1`$ 至少和 $`\pi_2`$ 一样好。这里比较整张价值表，而不是只比较某个起点，也不是先把所有状态的价值相加。

这种比较是偏序，不保证任意两套策略都能分出高下。例如，两套策略的价值若分别为 $`(6,2)`$ 与 $`(3,7)`$，前者在第一个状态更好，后者在第二个状态更好，谁也没有逐状态压过对方。

如果任务另外指定了起点分布 $`\mu(s)`$，可以用 $`\sum_s\mu(s)v_\pi(s)`$ 定义一个标量目标。但该目标只关注分布赋予权重的状态，与本课“对每个状态都最优”的定义需要区分。

### 1.2 最优价值与共同最优策略

先把每个状态能够达到的价值上界写为：

```math
v_*(s)=\sup_\pi v_\pi(s).
```

仅写下这个上确界，还没有证明它能被同一套策略同时达到。不能只凭“每个状态各有一个最好的策略”，就断言把这些策略随意拼接之后一定最好。

我们真正希望证明存在 $`\pi_*`$，使：

```math
v_{\pi_*}(s)=v_*(s)\geq v_\pi(s),
\qquad\text{对所有状态和任意策略 }\pi.
```

后面的不动点分析会完成这件事：先找到一张价值表，再根据它在每个状态选动作；由此得到的一套平稳策略能够共同达到这张表。

“平稳”表示动作规则不显式依赖时间。它不表示机器人一直做同一个动作；状态变化时，策略仍可输出不同动作。

## 2. 先用两状态工作区看清动机

沿用上一课的自编工作区。A 是普通任务区，B 是高收益任务区，过程可以无限持续，两个区域都不是终止状态。转移是确定性的：

| 当前状态 | 动作 | 即时奖励 | 下一状态 |
| --- | --- | ---: | --- |
| A | 留下工作 | $`1`$ | A |
| A | 去 B | $`0`$ | B |
| B | 留下工作 | $`4`$ | B |
| B | 去 A | $`0`$ | A |

先取 $`\gamma=0.5`$。上一课的一套随机策略是：在 A 以相同概率工作或去 B，在 B 始终工作。其价值为：

```math
v_\pi(A)=\frac{10}{3},\qquad v_\pi(B)=8.
```

根据这张表，在 A 给两个动作评分：

```math
q_\pi(A,\text{工作})
=1+0.5\times\frac{10}{3}
=\frac83,
```

```math
q_\pi(A,\text{去 B})=0+0.5\times8=4.
```

去 B 的分数更高。因此，如果目的是提高长期回报，在 A 就不必继续给“留下工作”一半的概率。

这里的评分包含后续价值。去 B 当前一步得 $`0`$，仍优于立即得 $`1`$ 的工作动作，因为到达 B 后可以反复获得较高奖励。

这个例子提出本课的核心问题：**能否找到一张价值表，使每个状态都按这张表选择最高分动作，而得到的长期价值又恰好就是这张表？**

## 3. 从策略分布的最大化得到动作的最大化

### 3.1 给定一张价值表，先给动作评分

对任意候选价值表 $`v`$，定义一步展望分数：

```math
q_v(s,a)
=\bar r(s,a)
+\gamma\sum_{s'}p(s'\mid s,a)v(s').
```

这里的下标 $`v`$ 提醒我们：它只是利用当前价值表算出的分数。只有当 $`v=v_\pi`$ 或 $`v=v_*`$ 时，才分别对应 $`q_\pi`$ 或 $`q_*`$。

若在状态 $`s`$ 使用动作分布 $`\pi(\cdot\mid s)`$，其加权分数是：

```math
\sum_a\pi(a\mid s)q_v(s,a),
\qquad
\pi(a\mid s)\geq0,\quad\sum_a\pi(a\mid s)=1.
```

### 3.2 为什么随机分配概率不能超过最高分

令 $`M=\max_a q_v(s,a)`$。每个动作的分数都不大于 $`M`$，因此：

```math
\sum_a\pi(a\mid s)q_v(s,a)
\leq\sum_a\pi(a\mid s)M=M.
```

选择一个达到最高分的动作 $`a_*`$，并把概率全部放给它，就能取得等号。所以：

```math
\max_{\pi(\cdot\mid s)}
\sum_a\pi(a\mid s)q_v(s,a)
=\max_a q_v(s,a).
```

这不是假设“随机策略一定差”，而是一个关于加权平均的结论。如果有多个动作并列最高，只在这些动作之间随机分配概率，也能取得相同最大值。

### 3.3 贝尔曼最优公式

把最优后续价值作为 $`v`$，得到：

```math
\boxed{
v_*(s)=\max_a
\left[
\bar r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v_*(s')
\right]
}.
```

这就是贝尔曼最优公式，英文简称 BOE。

若奖励本身是随机的，可以写：

```math
\bar r(s,a)=\sum_r p(r\mid s,a)r.
```

也可以把奖励与下一状态的联合分布写进同一个期望：

```math
v_*(s)
=\max_a\mathbb E
\left[R_{t+1}+\gamma v_*(S_{t+1})
\mid S_t=s,A_t=a\right].
```

**这里不要求奖励和下一状态相互独立。**期望的线性性允许把两项分别求期望。如果使用条件奖励 $`\bar r(s,a,s')`$，同一公式应写成：

```math
v_*(s)
=\max_a\sum_{s'}p(s'\mid s,a)
\left[\bar r(s,a,s')+\gamma v_*(s')\right].
```

记号不同，表达的仍然是同一个一步分解。

## 4. 公式里几个容易混淆的位置

### 4.1 最大化放在对下一状态求期望的外面

智能体先根据当前状态选动作，环境随后产生下一状态。因此，正确的决策顺序是先对每个可行动作计算期望，再比较这些期望。

不能擅自把 $`\max_a\mathbb E[\cdots\mid s,a]`$ 换成“看到下一状态以后再为刚才那一步挑动作”。后者相当于允许决策者提前知道本来尚未发生的随机结果，通常会高估可达到的收益。

### 4.2 不能只给即时奖励取最大值

一般情况下：

```math
\max_a\left[\bar r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v_*(s')\right]
```

不等于分别把奖励项、未来项各自取最大值后相加。这两个最大值可能来自不同动作，不能把两种动作的好处合并成一个实际不存在的动作。

### 4.3 max 给数值，argmax 给动作集合

```math
v_*(s)=\max_a q_*(s,a),
\qquad
a_*(s)\in\arg\max_a q_*(s,a).
```

前者给出最优价值的数字，后者给出取得这个数字的动作。用集合包含符号 $`\in`$ 是为了容纳并列最优。

### 4.4 这是整张表的联立方程

某个状态的价值依赖其他状态，而那些状态又可能转移回来，因此通常不能孤立地求一个状态。贝尔曼最优公式为每个状态提供一个方程，所有方程共同确定价值向量。

固定策略的贝尔曼公式可以写成线性方程。最优公式因为 $`\max`$ 可能随价值变化而选择不同动作，整体上通常是分段线性的非线性方程，不能先随意固定一个 $`P_\pi`$ 就当作最优解。

### 4.5 终止状态的边界条件也属于任务定义

如果一个状态表示回合已经结束，且结束后不再产生奖励，通常约定它的价值为零：

```math
v_*(s_{\mathrm{terminal}})=0.
```

到达终点时的成功奖励属于“进入终点的那次转移”，仍应计入 $`R_{t+1}`$。从终点出发的后续价值为零，并不表示刚刚到达终点没有奖励。

也可以给终止状态添加零奖励的吸收自环。此时 $`v=0+\gamma v`$ 的唯一解仍然是零，两种表达一致。若所谓“目标状态”允许继续工作并反复获得奖励，它就不是这个意义上的终止状态；例如本文的 B 区价值为 $`8`$，不能因为它比较理想就把它强制设成零。

## 5. 用算子表达整张价值表的更新

定义贝尔曼最优算子 $`T_*`$：

```math
(T_*v)(s)
=\max_a
\left[\bar r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v(s')\right].
```

“算子”在这里就是一套输入旧价值表、输出新价值表的运算。贝尔曼最优公式变成：

```math
v_*=T_*v_*.
```

满足这个关系的表是不动点：再更新一次，得到的仍然是自己。

沿用上一课的矩阵记法，也可以写：

```math
T_*v=\max_\pi(r_\pi+\gamma P_\pi v).
```

这里的最大化逐状态进行，不是把向量先求和再取最大值。它之所以可行，依赖策略能够在每个状态分别选择动作。

接下来需要分别证明三件事：不动点存在且唯一；从任意有限初值可以逼近它；这个不动点确实就是最优价值。

## 6. 为什么这个方程有唯一解

### 6.1 衡量两张价值表的最大差距

对两张表 $`u,v`$，定义最大范数：

```math
\|u-v\|_\infty=\max_s|u(s)-v(s)|.
```

它表示所有状态中相差最多的那个数值。记这个差距为 $`\delta`$。

对同一个状态、同一个动作，两张表给出的评分之差满足：

```math
\begin{aligned}
|q_u(s,a)-q_v(s,a)|
&=\gamma\left|\sum_{s'}p(s'\mid s,a)[u(s')-v(s')]\right|\\
&\leq\gamma\sum_{s'}p(s'\mid s,a)|u(s')-v(s')|\\
&\leq\gamma\delta.
\end{aligned}
```

即时奖励在相减时消掉；概率加权平均不会放大最大差距；折扣因子进一步缩小差距。

还需要一个不等式：

```math
\left|\max_a x_a-\max_a y_a\right|
\leq\max_a|x_a-y_a|.
```

即使两组分数选出了不同的最高分动作，这个不等式仍然成立。因为每个 $`x_a`$ 都至多比相应的 $`y_a`$ 高出右侧那个最大差距，反过来也一样。

于是：

```math
\boxed{
\|T_*u-T_*v\|_\infty
\leq\gamma\|u-v\|_\infty
}.
```

这就是压缩性质。$`\gamma=0`$ 时，算子完全不依赖输入，结论也成立。

### 6.2 压缩映射定理带来什么

有限维实数空间在最大范数下是完备的。压缩映射定理保证 $`T_*`$ 有唯一不动点，暂记作 $`w`$，并且从任意有限初值反复更新：

```math
v_{k+1}=T_*v_k,
```

都收敛到 $`w`$。

唯一性很容易看见。如果 $`w,z`$ 都是不动点，则：

```math
\|w-z\|_\infty
=\|T_*w-T_*z\|_\infty
\leq\gamma\|w-z\|_\infty.
```

由于 $`\gamma<1`$，只能有 $`\|w-z\|_\infty=0`$，即两张表完全相同。

而从任意初值出发的误差有上界：

```math
\|v_k-w\|_\infty
\leq\gamma^k\|v_0-w\|_\infty.
```

初值影响前几轮的结果和计算量，但在这些条件下不会改变最终不动点。这个结论说的是最大误差上界，不要求每个状态的数值都单调变化。

### 6.3 小变化与小误差之间的联系

若当前表的贝尔曼残差为：

```math
\varepsilon=\|T_*v-v\|_\infty,
```

利用三角不等式与压缩性质，有：

```math
\|v-w\|_\infty
\leq\varepsilon+\gamma\|v-w\|_\infty
\quad\Rightarrow\quad
\|v-w\|_\infty\leq\frac{\varepsilon}{1-\gamma}.
```

因此，停止更新并非只能凭感觉。但当 $`\gamma`$ 很接近 $`1`$ 时，同样大小的残差对应较宽的误差上界，需要更严格的精度要求。

## 7. 为什么唯一不动点就是最优价值

方程有唯一解，还不等于已经解释了它和真实策略回报的关系。这一步需要把数学上的自洽表 $`w`$ 与策略价值连接起来。

### 7.1 任意固定策略都达不到比它更高的价值

记固定策略的算子为：

```math
(T_\pi v)(s)
=\sum_a\pi(a\mid s)
\left[\bar r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v(s')\right].
```

因为最大值不小于任意动作分布的平均值：

```math
w=T_*w\geq T_\pi w.
```

这里以及下面的大小关系都逐状态成立。$`T_\pi`$ 保持大小关系：输入表逐状态更大，输出表也逐状态不小。因此可以继续迭代：

```math
w\geq T_\pi w\geq T_\pi^2w\geq\cdots
\longrightarrow v_\pi.
```

固定策略评估的极限是 $`v_\pi`$，所以 $`w\geq v_\pi`$。

### 7.2 至少有一套策略恰好达到它

在每个状态，从以下集合任选一个动作：

```math
a_w(s)\in\arg\max_a
\left[\bar r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)w(s')\right].
```

动作集合有限，最大值能够取得。令 $`\pi_w`$ 始终选择该动作，那么：

```math
w=T_*w=T_{\pi_w}w.
```

这说明 $`w`$ 同时满足策略 $`\pi_w`$ 的普通贝尔曼公式。固定策略的贝尔曼公式解唯一，因此：

```math
w=v_{\pi_w}.
```

一方面任意策略的价值不超过 $`w`$，另一方面同一套平稳确定性策略 $`\pi_w`$ 在所有状态都达到 $`w`$，所以：

```math
\boxed{w=v_*,\qquad\pi_w\text{ 是最优策略}}.
```

这也补上了最开始的存在性问题。若把竞争对象放宽到依赖历史或时间的策略，在马尔可夫状态充分、无限折扣任务的同样条件下，沿每一步展开 $`w(s)\geq\mathbb E[R_{t+1}+\gamma w(S_{t+1})]`$，也能得到它们的回报不超过 $`w`$；末尾的有界尾项会随折扣趋于零。

## 8. 完整计算工作区的最优价值与动作价值

取 $`\gamma=0.5`$，工作区的 BOE 是：

```math
v_*(A)=\max\{1+0.5v_*(A),\;0.5v_*(B)\},
```

```math
v_*(B)=\max\{4+0.5v_*(B),\;0.5v_*(A)\}.
```

先尝试候选策略“A 去 B，B 工作”。它的普通贝尔曼公式给出：

```math
v(B)=4+0.5v(B)\Rightarrow v(B)=8,
\qquad
v(A)=0+0.5\times8=4.
```

**解出这套策略的价值还不够，必须检查它是否满足最大化。**把 $`(4,8)`$ 代回每个动作：

| 状态 | 动作 | 按候选表计算的一步评分 |
| --- | --- | ---: |
| A | 工作 | $`1+0.5\times4=3`$ |
| A | 去 B | $`0+0.5\times8=4`$ |
| B | 工作 | $`4+0.5\times8=8`$ |
| B | 去 A | $`0+0.5\times4=2`$ |

每个状态的最大评分分别为 $`4`$、$`8`$，与候选表完全相同。因此它满足 BOE；由唯一性可知：

```math
\boxed{v_*(A)=4,\qquad v_*(B)=8}.
```

上表也给出了四个 $`q_*`$。最优动作是在 A 去 B、在 B 工作。

可以直接从实际奖励序列核对。在 B 连续工作：

```math
G_B=4+0.5\times4+0.5^2\times4+\cdots=8.
```

从 A 出发第一步去 B，当步奖励是 $`0`$，下一步才开始工作：

```math
G_A=0+0.5\times4+0.5^2\times4+\cdots=4.
```

第一笔奖励不乘折扣，第二笔才乘 $`\gamma`$。如果错误地让到达 B 的那一步也获得工作奖励，就改变了任务定义，算出来的将是另一个 MDP。

## 9. 动作价值形式：第一步可以指定，之后最优

最优动作价值定义为：

```math
q_*(s,a)=\sup_\pi q_\pi(s,a).
```

它的含义是：在状态 $`s`$ 先强制执行动作 $`a`$，随后采用最优行为时的期望回报。因此，非最优动作也有自己的 $`q_*`$；星号并不表示“第一个动作本身一定最优”。

状态价值与动作价值的关系是：

```math
q_*(s,a)
=\bar r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v_*(s'),
```

```math
v_*(s)=\max_a q_*(s,a).
```

把第二式代入第一式，得到动作价值形式的 BOE：

```math
\boxed{
q_*(s,a)
=\bar r(s,a)
+\gamma\sum_{s'}p(s'\mid s,a)\max_{a'}q_*(s',a')
}.
```

本次动作 $`a`$ 已经指定，下一状态的动作 $`a'`$ 才取最大值。两个动作处于不同的时间位置。

如果已经知道完整 $`q_*`$ 表，就能直接在每个状态比较动作。只有 $`v_*`$ 时，一般还需要奖励和转移模型来算一步评分。这里说明了两种表示在决策时的信息需求；如何在未知模型下学习 $`q_*`$，将由后续算法章节讨论。

## 10. 最优价值唯一，为什么最优策略仍可能有很多套

由压缩性质，$`v_*`$ 唯一；由它定义的 $`q_*`$ 也唯一。但在某个状态，多个动作可能有相同的最优动作价值。

定义最优动作集合：

```math
\mathcal A_*(s)=\{a:q_*(s,a)=v_*(s)\}.
```

在每个状态从 $`\mathcal A_*(s)`$ 任选一个动作，可以构成确定性最优策略；只把概率分配给集合内动作，也可以构成随机最优策略。若对严格次优动作分配正概率，该状态下的平均评分就会下降，不能再共同达到 $`v_*`$。

工作区在 $`\gamma=0.5`$ 时，两个状态的最优动作都没有并列。但把折扣因子改为 $`\gamma=0.25`$，有：

```math
v_*(B)=\frac4{1-0.25}=\frac{16}{3},
\qquad
v_*(A)=\frac43.
```

这时 A 的两个动作评分恰好相等：

```math
q_*(A,\text{工作})=1+0.25\times\frac43=\frac43,
```

```math
q_*(A,\text{去 B})=0.25\times\frac{16}{3}=\frac43.
```

因此，在 A 一直工作、立即去 B，或者每次在两者之间随机选择，都可以最优；B 则继续工作。策略不同，最优价值表相同。

这个结论也说明：**环境随机，不等于最优策略必须随机。**在本课有限折扣 MDP 的条件下，总存在一套确定性平稳最优策略；随机最优策略可以出现在并列最优动作之间。

## 11. 折扣因子与奖励怎样改变最优策略

### 11.1 折扣因子改变的是远期奖励的权重

在工作区中，留在 A 一直工作与立即前往 B 的价值分别为：

```math
\frac1{1-\gamma},
\qquad
\frac{4\gamma}{1-\gamma}.
```

比较后可知：$`\gamma>0.25`$ 时去 B 更好，$`\gamma<0.25`$ 时留在 A 更好，等于 $`0.25`$ 时并列。B 一直工作的价值为 $`4/(1-\gamma)`$；代回 BOE 可验证这套分情况结论。

因此，折扣因子不仅影响价值数字，还可能改变动作选择。它体现时间偏好，不应直接等同于“风险厌恶程度”；环境中的概率风险、奖励大小与时间分布都需要分别分析。

当 $`\gamma=0`$ 时：

```math
v_*(s)=\max_a\bar r(s,a).
```

此时只比较一步期望奖励，未来收益不进入目标。但 $`\gamma=1`$ 不能直接代入前面的无限折扣证明。工作区中 B 每步获得正奖励，未折扣回报发散；某些必然终止且回报有限的任务仍可分析，需要另外证明存在性和收敛性。

### 11.2 正比例缩放奖励保持策略排序

如果每次奖励统一乘 $`\alpha>0`$，同一条轨迹和同一套策略的回报也乘 $`\alpha`$：

```math
v'_\pi(s)=\alpha v_\pi(s),
\qquad
q'_\pi(s,a)=\alpha q_\pi(s,a).
```

因此策略和动作的大小关系保持，最优策略集合也保持。若乘负数，大小关系反转；若乘零，原先不同的回报都变成零，不能用同一个结论描述。

### 11.3 持续式无限折扣任务中的统一平移

若同一个无限时间序列上的**每一步**奖励都统一变换为：

```math
R'_{t+1}=\alpha R_{t+1}+\beta,
\qquad\alpha>0,
```

则：

```math
\begin{aligned}
G'_t
&=\sum_{k=0}^\infty\gamma^k(\alpha R_{t+k+1}+\beta)\\
&=\alpha G_t+\frac{\beta}{1-\gamma}.
\end{aligned}
```

所有策略从同一状态出发都增加相同常数，因此：

```math
v'_*=\alpha v_*+\frac{\beta}{1-\gamma}\mathbf1,
\qquad
q'_*(s,a)=\alpha q_*(s,a)+\frac{\beta}{1-\gamma}.
```

动作排序不变。这对应教材第三章的奖励仿射变换性质。它的关键前提是：每套策略都处于相同的无限折扣时间框架，且所有步骤都接受同一变换。

### 11.4 理解补充：变长回合中，“每步加常数”可能改变最优策略

若回报只累计到终止时刻 $`T`$，终止后不再发奖励，则：

```math
G'_t=\alpha G_t+
\beta\sum_{k=0}^{T-t-1}\gamma^k.
```

新增项可能随策略控制的回合长度变化，不能当作对所有策略相同的常数。

例如，一个自编的两路线任务中，短路线一步结束、奖励为 $`1`$；长路线两步结束、奖励依次为 $`0,1`$。取 $`\gamma=0.9`$：

| 规则 | 短路线回报 | 长路线回报 | 更优路线 |
| --- | ---: | ---: | --- |
| 原奖励 | $`1`$ | $`0+0.9\times1=0.9`$ | 短路线 |
| 终止前每步奖励都加 $`2`$ | $`3`$ | $`2+0.9\times3=4.7`$ | 长路线 |

最优选择改变了。把终止状态表示为零奖励吸收自环时，如果平移后仍强制终止后的奖励为零，就没有对那些吸收步骤实施同一个平移，所以也不满足前一小节的条件。

同理，在机器人任务中，“只给每个存活步加奖励”“只惩罚移动步”“改变失败后的终止方式”，都是任务设计的一部分。分析策略是否保持时，要先明确哪些时间步计入回报、终止后如何处理、奖励究竟改了哪些项。

### 11.5 零即时奖励的绕路，也可能受到折扣的影响

另设一个自编的确定性到达任务：直接走，两步后获得一次正奖励 $`10`$；绕路走，四步后才获得同样的奖励。途中奖励均为零，到达后终止。取 $`\gamma=0.9`$，从出发前开始计回报：

```math
G_{\mathrm{direct}}=0+0.9\times10=9,
```

```math
G_{\mathrm{detour}}
=0+0.9\times0+0.9^2\times0+0.9^3\times10
=7.29.
```

尽管每个中间步都没有直接受到惩罚，延迟正回报本身就会降低折扣回报。这个算例解释了为什么某些任务无须另加“每步负奖励”，也能偏好更早到达。

但需要保留比较的条件：两条路线最终获得同样的正奖励，中途收益相同，只是时间不同。如果绕路能获得额外奖励、减少失败概率，或者未来等待的是负收益，单凭路线更长就不能判定其价值更低。折扣按时间改变奖励权重，是否构成绕路、等待还是合理规避，要结合完整回报判断。

### 11.6 “有惩罚”不等于“绝对禁止”

如果一次违规只扣有限分数，智能体仍可能用这笔惩罚交换更大的未来奖励。BOE 比较的是总和，并不自动把某个负奖励视为不可违反的约束。

例如，为了得到远处的长期高收益，支付一次能耗成本可能是合理选择；但如果某个状态代表真实的碰撞危险，是否可以用奖励权重表达，需要另外考虑控制约束与安全机制。这里首先应分清数学任务中的“偏好某行为”和“某行为根本不可行”：前者改变奖励，后者改变可行动作集合或转移规则，它们在公式中位于不同的位置。

## 12. 把这一课放回机器人控制问题

| 数学对象 | 在机器人学习中的一种对应 | 需要注意 |
| --- | --- | --- |
| $`s`$ | 机体运动状态、关节状态、任务目标等 | 状态需足以描述后续转移，单帧观测未必满足马尔可夫性质 |
| $`a`$ | 力矩、关节目标或高层指令 | 不同控制层级对应不同动作定义 |
| $`\bar r(s,a)`$ | 一步的跟踪、稳定性、能耗等期望评分 | 奖励分项的相对权重会影响最优行为 |
| $`p(s'\mid s,a)`$ | 动力学及接触、扰动产生的转移规律 | 数学上定义了模型，不表示实际训练时已知道模型 |
| $`v_*(s)`$ | 从当前状态开始能够达到的最优期望折扣回报 | 价值依赖完整任务定义与折扣因子 |
| $`q_*(s,a)`$ | 先执行指定控制动作、随后最优控制的期望回报 | 当前奖励较差的动作仍可能具有较高长期价值 |

BOE 说明了怎样把长期目标压缩到“一步奖励与后续价值”的比较中。它本身并未解决连续高维状态、未知动力学、函数近似误差与样本效率等问题；后续课程的算法是在不同信息和表示条件下逐步处理这些问题。

## 13. 本课符号与下一课入口

| 符号 | 含义 |
| --- | --- |
| $`v_\pi(s)`$ | 固定策略的状态价值 |
| $`v_*(s)`$ | 逐状态最优价值 |
| $`q_v(s,a)`$ | 使用任意候选价值表的一步展望分数 |
| $`q_*(s,a)`$ | 第一动作指定、随后最优时的动作价值 |
| $`T_\pi`$ | 固定策略的贝尔曼算子 |
| $`T_*`$ | 贝尔曼最优算子 |
| $`\max`$ | 最高分的数值 |
| $`\arg\max`$ | 取得最高分的动作集合 |
| $`\|u-v\|_\infty`$ | 两张表逐状态差距的最大绝对值 |

这一课建立了完整的逻辑链：**最优性定义 → 对动作分布求最大值 → BOE → 压缩与唯一不动点 → 从不动点构造共同最优策略。**

第 4 课将把这些性质变成计算流程：值迭代直接更新最优价值估计；策略迭代交替进行固定策略评估与策略改善。两者中的“当前价值”含义不同，另见独立的[学习追问：值迭代与策略迭代](/posts/value-vs-policy-iteration/)。
